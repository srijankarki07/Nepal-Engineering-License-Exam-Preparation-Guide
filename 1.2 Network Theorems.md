# 1.2 NETWORK THEOREMS

### 1. Superposition Theorem

**Statement:**
In a linear circuit with multiple independent sources (voltage or current), the **response (current or voltage) in any branch** is equal to the **sum of the responses produced by each source acting alone**, with all other sources replaced by their internal resistances.

**Procedure:**

1. Keep **one source active** at a time.

   - Replace other **voltage sources** with **short circuits (0 V)**.
   - Replace other **current sources** with **open circuits (0 A)**.

2. Calculate current/voltage due to each source separately.
3. **Add algebraically** all individual responses.

**Valid for:** Linear and bilateral circuits.
**Not valid for:** Non-linear circuits (like diode circuits).

**Example Question:**

> Superposition theorem is applicable to:<br>
> A. Linear circuits only<br>
> B. Non-linear circuits<br>
> C. Magnetic circuits<br>
> D. All of the above<br>

## **_Answer: A_**

### 2. Thevenin’s Theorem

**Statement:**
Any two-terminal linear network can be replaced by an **equivalent voltage source (Vth)** in series with an **equivalent resistance (Rth)**.

### 3. Norton’s Theorem

**Statement:**
Any two-terminal linear network can be replaced by an **equivalent current source (IN)** in **parallel** with an **equivalent resistance (RN)**.

### 4. Maximum Power Transfer Theorem

**Statement:**
Maximum power is transferred to the load when **load resistance (RL)** is **equal to the Thevenin resistance (Rth)** of the source network.
