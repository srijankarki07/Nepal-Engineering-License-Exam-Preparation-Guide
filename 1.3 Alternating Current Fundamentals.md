# 1.3 ALTERNATING CURRENT FUNDAMENTALS

### 1. Principle of Generation of Alternating Voltage & Current

**Concept:**
When a **conductor rotates in a magnetic field**, the **magnetic flux** linking the coil changes continuously.
According to **Faraday’s Law of Electromagnetic Induction**, an **EMF (voltage)** is induced in the conductor.

![alt text](/assets/image-11.png)

If the conductor rotates **uniformly** in a **uniform magnetic field**, the induced voltage **varies sinusoidally** with time — i.e., it is **alternating**.

### 2. Waveforms and Basic Terms

#### (a) Cycle

One complete set of positive and negative alternations.

#### (b) Frequency (f)

Number of cycles per second (Hz).
In Nepal/India → 50 Hz → means 50 cycles/sec.

#### (c) Time Period (T)

Time for one complete cycle.
<br>
<br>
T = \1/f

#### (d) Amplitude (Em or Im)

Maximum value of voltage or current.

#### (e) Angular Frequency (ω)

ω = 2πf
<br>
→ Measured in radians/sec.

### 4. Relationship Between Voltage and Current in AC Circuits

| Circuit Type     | Phase Relationship               | Power Factor     |
| ---------------- | -------------------------------- | ---------------- |
| Pure Resistance  | Voltage and current **in phase** | pf = 1           |
| Pure Inductance  | Current **lags voltage by 90°**  | pf = 0 (lagging) |
| Pure Capacitance | Current **leads voltage by 90°** | pf = 0 (leading) |

---

### 5. Single-Phase vs. Three-Phase System

#### (a) Single-Phase System

- Only **one alternating voltage**.
- Supply has **two wires** — phase and neutral.
- Used for: domestic lighting, fans, small loads (<1 kW).

#### (b) Three-Phase System

- Has **three alternating voltages** of **equal magnitude** but **120° phase difference**.
- Generated by a **3-phase alternator**.
- Used for: transmission, industries, motors.

**Why three-phase?**

- Constant power delivery
- Smaller conductor size
- Better efficiency
