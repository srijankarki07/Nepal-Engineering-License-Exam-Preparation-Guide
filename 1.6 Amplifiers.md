# 1.6 Amplifiers

### What is an Amplifier?

An **amplifier** is an electronic circuit that **increases the amplitude** (strength) of a weak input signal **without changing its shape**.

In simple words:

> Amplifier = Device that boosts voltage, current, or power of a signal.

---

### Basic Concept

- **Input signal**: weak voltage or current
- **Output signal**: same waveform but larger amplitude
- **Power source**: provides the energy for amplification

Amplifiers obey **energy conservation** — they _do not create energy_, they use DC power supply to increase the signal strength.

---

## Classification of Amplifiers

Amplifiers can be classified based on different criteria:

| Basis               | Types                                                 |
| ------------------- | ----------------------------------------------------- |
| **Signal type**     | Voltage amplifier, Current amplifier, Power amplifier |
| **Frequency range** | Audio (AF), Radio Frequency (RF), Wideband            |
| **Stage coupling**  | RC coupled, Transformer coupled, Direct coupled       |
| **Operation class** | Class A, Class B, Class AB, Class C                   |
| **Active device**   | BJT, FET, MOSFET, Op-amp                              |

---

## Output Stage Classification (Power Amplifiers)

The **output stage** of an amplifier handles **large current and power**.
Let’s understand each class:

---

### **1. Class A Amplifier**

- **Transistor conducts for full 360°** of the input signal.
- Output waveform is a **complete replica** of input.
- **Highest fidelity** (no distortion).
- **Efficiency:** Low (~25–30%) because transistor always conducts, wasting power as heat.

  **Used in:** Audio amplifiers (where distortion must be minimal)

---

### **2. Class B Amplifier**

- **Transistor conducts for 180°** (half cycle) of the input.
- Uses **two transistors** — one for positive half, another for negative half (called **push-pull configuration**).
- **Efficiency:** Higher (~78.5%)
- **Drawback:** “Crossover distortion” around zero crossing point.

**Used in:** Power output stages (e.g., audio power amplifiers)

---

### **3. Class AB Amplifier**

- **Transistor conducts for slightly more than 180°** (less than 360°).
- Designed to **eliminate crossover distortion** but still improve efficiency.
- **Efficiency:** Between A and B (~50–70%)
- **Most common type** in modern audio amplifiers.

**Used in:** Hi-fi systems, speaker amplifiers.

---

### **4. Class C Amplifier**

- **Conduction angle < 180°**
- Produces **high distortion**, not suitable for audio.
- Very **high efficiency (≈ 80–90%)**
- Used in **RF transmission** (after tuning).

  **Used in:** Radio frequency oscillators and transmitters.

---

### Comparison Summary:

| Class | Conduction Angle | Efficiency | Distortion         | Application     |
| ----- | ---------------- | ---------- | ------------------ | --------------- |
| A     | 360°             | 25–30%     | Low                | Audio preamp    |
| B     | 180°             | ~78%       | Medium (crossover) | Power stage     |
| AB    | 180–360°         | 50–70%     | Low                | Audio output    |
| C     | <180°            | Up to 90%  | High               | RF transmitters |

---

## Biasing the Class AB Stage

To avoid crossover distortion, **Class AB** uses a small **bias voltage** so both transistors are slightly “on” even when input = 0V.

- This ensures smooth transition between positive and negative halves.
- Bias can be provided by **diodes or resistor network**.

---

## Power BJTs (Bipolar Junction Transistors)

PowerBJTs are **designed to handle high voltage and current**.

Differences from normal BJTs:

- Larger junction area (for high current)
- Thick collector region (for high voltage)
- Mounted on **heat sinks** (for thermal dissipation)

  **Used in:** Audio power amplifiers, power supplies, motor drivers.

---

## Transformer-Coupled Push-Pull Stage

- Two transistors used in **push-pull configuration** (one for +ve half, one for –ve half).
- Transformer:

  - Provides **phase splitting** (center-tapped)
  - Matches **load impedance**
  - Helps improve **power transfer efficiency**

Used in: **Class B output stages**.

---

## Tuned Amplifiers

A **tuned amplifier** uses a **resonant LC circuit** in the collector or drain.

- Selects a **specific frequency** (resonance frequency).
- Amplifies only that frequency — **rejects others**.
- **High selectivity and gain** at resonance.

**Used in:** Radio receivers, RF amplifiers.

## Operational Amplifier (Op-Amp)

A **high-gain voltage amplifier** with differential inputs and a single-ended output.

### Ideal Op-Amp characteristics:

- Infinite input impedance (no current drawn)
- Zero output impedance
- Infinite open-loop gain
- Infinite bandwidth
- Zero offset voltage

---

### Common Op-Amp Configurations:

#### 1. Inverting Amplifier:

- Input connected to **inverting (-)** terminal via resistor.
- Non-inverting (+) terminal is grounded.
- Output is **180° out of phase** with input.

![alt text](/assets/inverting.png)

---

#### 2. Non-Inverting Amplifier:

- Input to **non-inverting (+)** terminal.
- Output is **in phase** with input.

![alt text](/assets/non-inverting.png)

---

#### 3. Voltage Follower (Buffer):

- Output directly connected to input (-).
- Gain = 1
- Used for **isolation** (no loading effect).

## Exam Pointers (Frequently Asked MCQ Concepts)

- **Class A** → 360°, low efficiency
- **Class B** → 180°, push-pull
- **Class AB** → reduces crossover distortion
- **Class C** → <180°, used in RF
- **Tuned amplifier** → selective frequency amplification
- **Op-amp** → high gain differential amplifier
- **Inverting op-amp** → 180° phase shift
- **Non-inverting op-amp** → no phase shift
- **Transformer coupling** → impedance matching
- **Power BJTs** → handle high power
