## **10.1 Engineering Drawings and Its Concepts**

### **1. Standard Drawing Sheets**

- **Purpose:** Provides uniform size and layout for all engineering drawings.
- **Sizes (ISO standard / common in Nepal):**

  | Sheet | Size (mm)  |
  | ----- | ---------- |
  | A0    | 841 × 1189 |
  | A1    | 594 × 841  |
  | A2    | 420 × 594  |
  | A3    | 297 × 420  |
  | A4    | 210 × 297  |

- **Orientation:**

  - **Portrait:** taller than wide
  - **Landscape:** wider than tall

- **Title Block:** Includes project name, drawing title, scale, designer’s name, date.

---

### **2. Dimensions**

- **What:** Measurements showing actual size of objects.
- **Units:** Usually **millimeters (mm)**.
- **Tolerances:** Allowable variation in size (e.g., ±0.5 mm).

---

### **3. Scale**

- **Purpose:** Shows object in reduced or enlarged size on paper.
- **Notation:** 1:1 (actual size), 1:2 (half size), 2:1 (double size).

**Example:**

- A table 2 m long → Drawn at 1:10 scale → 0.2 m on paper (20 cm).

---

### **4. Types of Lines**

| Line Type                    | Use                                |
| ---------------------------- | ---------------------------------- |
| Continuous Thick             | Visible edges                      |
| Continuous Thin              | Dimensions, hatching, leader lines |
| Dashed                       | Hidden edges                       |
| Chain (long dash–short dash) | Center lines, symmetry             |

**Tip:** “Dashed line represents?” → **hidden edges**.

---

### **5. Orthographic Projection**

- **Purpose:** Represent 3D object in **2D views**.
- **Views:** Front, top, side.
- **Key Point:** Shows **true shape and size**; no distortion.
- **Types:** First-angle (Europe/Asia) vs Third-angle (USA).

---

### **6. Isometric Projection / View**

- **Purpose:** Shows 3D object in **pseudo-3D** view.
- **Characteristics:**

  - Axes X, Y, Z at **120°** angles
  - Equal scale along all axes

- **Looks like:** 3D box on paper.

**Tip:** “Angle between axes in isometric drawing?” → 120°.

---

### **7. Pictorial Views**

- **Purpose:** Show object **as it appears visually**.
- **Types:**

  - **Oblique:** Front face true size, other lines at angle
  - **Perspective:** Appears realistic, vanishing point

---

### **8. Sectional Drawing**

- **Purpose:** Show **internal features** by cutting through the object.
- **Hatching / Crosshatch:** Indicates cut surfaces.
- **Uses:** Complex components like gears, engines, valves.

**Tip:** “Why use sectional view?” → **to show internal features**.

---

### **Summary**

| Concept               | Key Point                |
| --------------------- | ------------------------ |
| Sheet Sizes           | A0 largest → A4 smallest |
| Units for dimension   | mm                       |
| Scale notation        | 1:1, 1:2, 2:1            |
| Continuous thick line | Visible edge             |
| Dashed line           | Hidden edge              |
| Orthographic view     | True size & shape        |
| Isometric view        | Axes 120°, equal scale   |
| Pictorial view        | Realistic / oblique      |
| Sectional view        | Shows internal parts     |
