## **10.3 Project Planning and Scheduling**

### **1. Project Classifications**

Projects can be classified by:

- **Size:** Small, medium, large
- **Sector:** Civil, electrical, mechanical, IT
- **Cost & Duration:** Low cost vs high cost, short-term vs long-term

---

### **2. Project Life Cycle Phases**

**Definition:** All projects follow a standard lifecycle from start to finish.

**Phases:**

1. **Initiation:** Idea → feasibility study
2. **Planning:** Define objectives, activities, resources
3. **Execution:** Actual implementation
4. **Monitoring & Controlling:** Track progress, take corrective actions
5. **Closure:** Completion, handover, evaluation

---

### **3. Project Planning Process**

Steps to plan a project:

1. Define project objectives
2. Identify required activities/tasks
3. Allocate resources (manpower, material, equipment)
4. Develop schedule & budget
5. Identify risks & mitigation strategies

---

### **4. Project Scheduling**

**Purpose:** Determine timeline for project tasks.

**Methods:**

1. **Bar Chart / Gantt Chart**

   - Simple timeline showing **start & end dates** of tasks
   - Visual representation; easy for small projects

2. **Critical Path Method (CPM)**

   - Determines **longest path** of dependent tasks → **project duration**
   - Helps identify **critical activities** that cannot be delayed

3. **Program Evaluation & Review Technique (PERT)**

   - Uses **probabilistic time estimates**: optimistic (O), pessimistic (P), most likely (M)
   - Expected time:
     [
     TE = \frac{O + 4M + P}{6}
     ]

CPM → deterministic; PERT → probabilistic

---

### **5. Resource Leveling and Smoothing**

1. **Resource Leveling:** Adjust tasks to avoid **over-allocation of resources** (may extend project)
2. **Resource Smoothing:** Adjust tasks without changing **project duration**, to match resource availability

---

### **6. Monitoring, Evaluation, and Controlling**

- **Monitoring:** Track project progress vs plan
- **Evaluation:** Assess performance (time, cost, quality)
- **Controlling:** Correct deviations (adjust schedule, resources, scope)

---

### **Summary**

| Concept                | Key Point                                                |
| ---------------------- | -------------------------------------------------------- |
| Project Classification | Size, sector, cost, duration                             |
| Life Cycle Phases      | Initiation → Planning → Execution → Monitoring → Closure |
| Bar Chart / Gantt      | Visual timeline                                          |
| CPM                    | Longest path → project duration                          |
| PERT                   | Probabilistic, TE = (O+4M+P)/6                           |
| Resource Leveling      | Avoid over-allocation                                    |
| Resource Smoothing     | Adjust tasks without changing duration                   |

### **MCQs**

1. **Which is the correct sequence of project life cycle phases?**<br>
   A) Planning → Initiation → Execution → Closure → Monitoring<br>
   B) Initiation → Planning → Execution → Monitoring → Closure<br>
   C) Initiation → Execution → Planning → Closure → Monitoring<br>
   D) Planning → Execution → Initiation → Monitoring → Closure

   **Answer:** B) Initiation → Planning → Execution → Monitoring → Closure

   ***

2. **Which scheduling method uses a visual timeline?**<br>
   A) CPM<br>
   B) PERT<br>
   C) Gantt Chart<br>
   D) MARR<br>

   **Answer:** C) Gantt Chart

   ***

3. **Critical Path Method (CPM) helps to identify:**<br>
   A) Shortest path<br>
   B) Longest path / critical tasks<br>
   C) Resource allocation<br>
   D) Cost estimation

   **Answer:** B) Longest path / critical tasks

   ***

4. **PERT expected time formula is:**<br>
   A) (O + M + P)/3<br>
   B) (O + 4M + P)/6<br>
   C) (O + P)/2<br>
   D) (M + P)/2

   **Answer:** B) (O + 4M + P)/6

   ***

5. **Resource leveling is used to:**<br>
   A) Increase project duration<br>
   B) Avoid over-allocation of resources<br>
   C) Reduce cost<br>
   D) None

   **Answer:** B) Avoid over-allocation of resources

   ***

6. **Resource smoothing differs from leveling in that:**<br>
   A) May extend project duration<br>
   B) Adjusts tasks without changing project duration<br>
   C) Uses probabilistic time<br>
   D) Determines critical path

   **Answer:** B) Adjusts tasks without changing project duration

   ***

7. **Monitoring and controlling ensures:**<br>
   A) Project stays on track<br>
   B) Only cost is controlled<br>
   C) Only quality is monitored<br>
   D) Only resources are allocated

   **Answer:** A) Project stays on track

   ***

8. **Which of the following is NOT part of project planning?**<br>
   A) Define objectives<br>
   B) Allocate resources<br>
   C) Execute tasks<br>
   D) Identify risks

   **Answer:** C) Execute tasks

   ***

9. **A project classified based on sector can be:**<br>
   A) Civil<br>
   B) Electrical<br>
   C) IT<br>
   D) All of the above

   **Answer:** D) All of the above

   ***

10. **Which project scheduling technique is probabilistic?**<br>
    A) CPM<br>
    B) Gantt<br>
    C) PERT<br>
    D) MARR

    **Answer:** C) PERT
