## **10.4 Project Management**

### **1. Project Information System**

- **Definition:** A system that collects, stores, processes, and shares project information for decision-making.
- **Purpose:**

  - Track progress
  - Communicate status among stakeholders
  - Support planning and control

**Components:**

- Data collection (reports, updates)
- Processing (analyzing progress, cost, risk)
- Distribution (reports to team, clients, etc.)

_Project Information System supports planning, monitoring, and controlling._

---

### **2. Project Risk Analysis and Management**

- **Risk:** Uncertainty that can affect project objectives (time, cost, quality).
- **Types of Risks:**

  - **Technical risk:** design errors, technology issues
  - **Financial risk:** cost overruns, funding shortages
  - **Management risk:** poor planning, communication
  - **External risk:** weather, policy, social issues

**Risk Management Process:**

1. **Identify** risks
2. **Assess / Analyze** risks (probability & impact)
3. **Plan response** (avoid, reduce, transfer, accept)
4. **Monitor and control** risks continuously

---

### **3. Project Financing**

- **Definition:** Arranging funds to execute a project.
- **Sources of Finance:**

  - **Equity:** Owner’s investment
  - **Debt / Loan:** Borrowed from banks or institutions
  - **Grants / Aid:** Non-repayable funds (e.g., government or donors)

_Financial planning ensures smooth project execution without cash shortages._

---

### **4. Tender and Its Process**

- **Tender:** Official invitation to suppliers/contractors to submit bids for a project.
- **Tender Process Steps:**

  1. **Notice / Invitation to Tender**
  2. **Submission of Bids**
  3. **Bid Opening**
  4. **Bid Evaluation** (technical & financial)
  5. **Contract Award**

**Types of Tender:**

- **Open tender:** Anyone can bid
- **Selective tender:** Invited firms only
- **Negotiated tender:** Direct discussion with one or few contractors

---

### **5. Contract Management**

- **Definition:** Administration and enforcement of the terms in a contract throughout the project life cycle.
- **Purpose:**

  - Ensure performance according to terms
  - Manage changes, claims, and payments
  - Avoid disputes

**Types of Contracts:**

| Type                       | Description                               |
| -------------------------- | ----------------------------------------- |
| **Lump Sum / Fixed Price** | Contractor paid fixed total amount        |
| **Cost-Plus**              | Contractor reimbursed cost + fixed profit |
| **Time & Material**        | Based on time spent and materials used    |

---

### **Summary**

| Concept                    | Key Point                                              |
| -------------------------- | ------------------------------------------------------ |
| Project Information System | Collects, processes, distributes project data          |
| Risk Management Steps      | Identify → Analyze → Respond → Monitor                 |
| Project Financing          | Equity, debt, or grants                                |
| Tender Process             | Invitation → Submission → Opening → Evaluation → Award |
| Contract Types             | Fixed-price, cost-plus, time & material                |
