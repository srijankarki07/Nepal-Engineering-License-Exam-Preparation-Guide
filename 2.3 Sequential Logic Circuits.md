# 2.3 Sequential Logic Circuits

## Overview

**Combinational circuits** depend only on **current inputs**. <br>
**Sequential circuits** depend on **current inputs + past history (memory)**.

Sequential circuits use **storage elements** (like flip-flops) to store data which introduces the concept of **state**.

---

## 1. Types of Sequential Circuits

| Type             | Description                                              | Example                         |
| ---------------- | -------------------------------------------------------- | ------------------------------- |
| **Synchronous**  | All flip-flops triggered by a **common clock**           | Registers, Synchronous Counters |
| **Asynchronous** | Flip-flops triggered **individually** by previous output | Ripple Counters                 |

---

## 2. Basic Memory Element – Flip-Flop

A **flip-flop** is a **1-bit memory cell** — it stores either **0 or 1**.<br>
It has **two stable states**, hence also called a **bistable multivibrator**.

---

### Types of Flip-Flops

| Type         | Inputs             | Description                                |
| ------------ | ------------------ | ------------------------------------------ |
| RS Flip-Flop | R (Reset), S (Set) | Basic memory element                       |
| JK Flip-Flop | J, K               | Improved RS (no invalid state)             |
| D Flip-Flop  | D (Data)           | Simplest; stores input value on clock edge |
| T Flip-Flop  | T (Toggle)         | Toggles output on each pulse               |

---

## 3. RS Flip-Flop

### Inputs:

S = Set, R = Reset

| S   | R   | Q(next)   | Description     |
| --- | --- | --------- | --------------- |
| 0   | 0   | No Change | Memory state    |
| 0   | 1   | 0         | Reset           |
| 1   | 0   | 1         | Set             |
| 1   | 1   | Invalid   | Forbidden state |

_Used in basic latches (SR latch)_

---

## 4. Gated RS Flip-Flop

Adds a **clock (C)** input to control when the flip-flop changes.<br>
Output changes only when **C = 1** (active).

| C   | S   | R   | Next Q    |
| --- | --- | --- | --------- |
| 0   | X   | X   | No change |
| 1   | 0   | 1   | Reset     |
| 1   | 1   | 0   | Set       |
| 1   | 0   | 0   | No change |
| 1   | 1   | 1   | Invalid   |

_Clock input synchronizes operation._

---

## 5. Edge-Triggered Flip-Flops

Flip-flops that change output **only at the edge** (rising or falling) of the clock signal.

- **Positive edge**: triggered at ↑
- **Negative edge**: triggered at ↓

  _Used in all synchronous sequential circuits._

---

## 6. JK Flip-Flop

An improvement over RS Flip-Flop (removes invalid state).

| J   | K   | Q(next)   | Operation    |
| --- | --- | --------- | ------------ |
| 0   | 0   | No change | Hold         |
| 0   | 1   | 0         | Reset        |
| 1   | 0   | 1         | Set          |
| 1   | 1   | Toggle    | Complement Q |

_Toggling behavior is widely used in counters._

**Characteristic Equation:**<br>
Q(next) = J¯Q + ¯KQ

---

## 7. D Flip-Flop (Data / Delay Flip-Flop)

Simplest and most used flip-flop.

**Input:** D
**Output:** Q follows D on clock edge.

| D   | Q(next) |
| --- | ------- |
| 0   | 0       |
| 1   | 1       |

_Used for data storage, registers._

**Characteristic Equation:**<br>
Q(next) = D

---

## 8. T Flip-Flop (Toggle Flip-Flop)

Formed from JK by connecting J = K = T.

| T   | Q(next)             |
| --- | ------------------- |
| 0   | No change           |
| 1   | Toggle (Complement) |

_Used in counters._

**Characteristic Equation:**<br>
Q(next) = T⊕Q

---

## 9. Master-Slave Flip-Flop

Used to avoid **race-around condition** in JK flip-flops.<br>
It uses **two flip-flops in series** ; master (on leading edge) and slave (on trailing edge).

_Ensures stable output, even with high-frequency clock signals._

---

## 10. Registers

A **register** is a group of flip-flops used to **store multiple bits** (n flip-flops → n-bit register).

---

### Types of Registers

| Type                       | Description               |
| -------------------------- | ------------------------- |
| **Shift Register**         | Shifts data left or right |
| **Parallel Register**      | Loads all bits at once    |
| **Serial Register**        | Loads bits one by one     |
| **Bidirectional Register** | Shifts both left & right  |

---

### Applications of Shift Registers:

- Data storage and transfer
- Serial-to-parallel or parallel-to-serial conversion
- Delay elements
- Ring counters

---

### Types of Shift Registers:

| Type | Direction                | Example                       |
| ---- | ------------------------ | ----------------------------- |
| SISO | Serial In Serial Out     | Used for delay                |
| SIPO | Serial In Parallel Out   | Serial to parallel conversion |
| PISO | Parallel In Serial Out   | Parallel to serial conversion |
| PIPO | Parallel In Parallel Out | Simple data storage           |

---

## 11. Counters

A **counter** is a sequential circuit that **counts clock pulses**.

| Type                              | Triggering                              | Description      |
| --------------------------------- | --------------------------------------- | ---------------- |
| **Asynchronous Counter (Ripple)** | Flip-flops triggered by previous output | Simple, slower   |
| **Synchronous Counter**           | All flip-flops triggered by same clock  | Faster, reliable |

---

### Binary Counter Example (3-bit)

| Clock Pulse | Output (Q₂Q₁Q₀) | Decimal |
| ----------- | --------------- | ------- |
| 1           | 000             | 0       |
| 2           | 001             | 1       |
| 3           | 010             | 2       |
| 4           | 011             | 3       |
| 5           | 100             | 4       |
| ...         | ...             | ...     |

_Used in digital clocks, frequency dividers._

---

### Frequency Division:

In a counter, each flip-flop **divides the frequency by 2**.

So for an n-bit counter:
**Output frequency = Input frequency / 2ⁿ**

---

### Modulus of Counter

Number of unique states before repeating.

Example:

- 3-bit counter → Mod-8 (2³ = 8 states)
- 4-bit counter → Mod-16

---

## Quick Summary

| Concept            | Description                             | Key Point              |
| ------------------ | --------------------------------------- | ---------------------- |
| Sequential Circuit | Output depends on present & past inputs | Has memory             |
| Flip-Flop          | 1-bit storage                           | Bistable               |
| RS Flip-Flop       | Basic memory                            | Invalid at S=R=1       |
| JK Flip-Flop       | Toggle function                         | No invalid state       |
| D Flip-Flop        | Data storage                            | Q = D                  |
| T Flip-Flop        | Toggle on each pulse                    | Used in counters       |
| Master-Slave       | Two-stage FF                            | Removes race-around    |
| Register           | Group of FFs                            | Temporary data storage |
| Shift Register     | Shifts data                             | Used in conversion     |
| Counter            | Counts pulses                           | MOD = number of states |

---

## Sample NEC-style MCQs

**1. In a JK flip-flop, when J=K=1, the output will:**<br>
A) Set B) Reset C) No change D) Toggle<br>
**Answer:** D

---

**2. How many flip-flops are required for a 4-bit register?**<br>
A) 2 B) 4 C) 8 D) 16<br>
**Answer:** B

---

**3. The output frequency of a 3-bit ripple counter with 1 kHz input clock is:**<br>
A) 125 Hz B) 250 Hz C) 500 Hz D) 333 Hz<br>
**Answer:** A (1000 Hz ÷ 2³ = 125 Hz)

---

**4. Which flip-flop is free from the race-around condition?**<br>
A) RS B) D C) Master-Slave JK D) T<br>
**Answer:** C

---

**5. In a shift register, data movement occurs:**<br>
A) Randomly B) Sequentially C) Simultaneously D) By analog means<br>
**Answer:** B
