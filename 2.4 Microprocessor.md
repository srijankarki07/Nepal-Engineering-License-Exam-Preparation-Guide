## Internal Architecture and Features of Microprocessor

### What is a Microprocessor?

A **microprocessor** is a **programmable integrated circuit (IC)** that performs **arithmetic and logic operations**, controls devices, and processes data.<br>
It’s the **CPU on a single chip** — the “brain” of a computer or embedded system.

> **Definition:**
> A microprocessor is a semiconductor device that contains the arithmetic logic unit (ALU), control unit (CU), and register unit — capable of performing computing tasks according to instructions from memory.

---

### Basic Components of a Microprocessor

Let’s understand the internal architecture step by step (we’ll use **Intel 8085/8086** as base references since most NEC questions are based on these).

#### 1. Arithmetic and Logic Unit (ALU)

- Performs all **arithmetic** operations (addition, subtraction, increment, decrement, etc.).
- Performs **logical** operations (AND, OR, NOT, XOR, compare).
- Sets **flag bits** (e.g., Zero flag, Carry flag, Sign flag) based on results.

#### 2. Register Array

Registers are **high-speed memory locations inside the CPU** for temporary data storage.

Common registers:

| Register                 | Size       | Use                                                     |
| ------------------------ | ---------- | ------------------------------------------------------- |
| **Accumulator (A)**      | 8-bit      | Stores results of operations                            |
| **B, C, D, E, H, L**     | 8-bit each | General purpose (can form 16-bit pairs like BC, DE, HL) |
| **Program Counter (PC)** | 16-bit     | Holds the address of the next instruction               |
| **Stack Pointer (SP)**   | 16-bit     | Points to the top of the stack in memory                |
| **Flag Register**        | 8-bit      | Stores status bits (Zero, Sign, Carry, etc.)            |

---

#### 3. Control Unit (CU)

- Directs operation of ALU, memory, and I/O.
- Generates **timing and control signals** to coordinate execution.
- Fetches, decodes, and executes instructions.

---

#### 4. Bus System

Microprocessor communicates through **buses** <br>sets of parallel wires that transfer data, address, and control signals.

| Bus Type        | Function                                         | Width (in 8085)            |
| --------------- | ------------------------------------------------ | -------------------------- |
| **Address Bus** | Carries memory addresses                         | 16-bit (can address 64 KB) |
| **Data Bus**    | Carries data                                     | 8-bit                      |
| **Control Bus** | Carries control signals (Read/Write, Interrupts) | Variable                   |

---

#### 5. Clock and Timing Circuit

- Synchronizes all internal operations.
- Frequency of clock = **Speed of microprocessor** (e.g., 8085 runs at 3 MHz).

---

#### 6. Interrupt Control

- Handles external/internal signals that **interrupt normal execution**.
- Microprocessor temporarily stops current work to service urgent requests.

---

#### 7. Memory Interface

- Provides mechanism to **read/write** data to/from memory.
- Divided into:

  - **Program Memory (ROM):** Stores instructions.
  - **Data Memory (RAM):** Stores temporary data and results.

---

### Microprocessor Classification (based on bit size)

| Type   | Example         | Address Range             |
| ------ | --------------- | ------------------------- |
| 4-bit  | Intel 4004      | 2⁴ = 16 locations         |
| 8-bit  | Intel 8085, Z80 | 2¹⁶ = 64 KB               |
| 16-bit | Intel 8086      | 2²⁰ = 1 MB                |
| 32-bit | Intel 80386     | 2³² = 4 GB                |
| 64-bit | Core i7         | 2⁶⁴ (virtually unlimited) |

---

### Features of Intel 8085 Microprocessor (Common in NEC Questions)

- 8-bit processor
- 16-bit address bus (64 KB memory)
- 8-bit data bus
- 74 instructions, 5 flags
- 5 interrupt lines
- Requires +5V single power supply
- Operates at 3 MHz clock speed

## Assembly Language Programming (ALP)

### What is Assembly Language?

Assembly Language is a **low-level programming language** for microprocessors, using **mnemonics (symbolic names)** instead of binary machine codes.

> Example:
> Instead of writing `00111110 00001010`, we write
> `MVI A, 0AH` (Move 0AH into accumulator)

---

### Structure of an Assembly Program

Typical assembly program structure:

```
ORG 2000H     ; Starting address
MVI A, 05H    ; Load 05H into accumulator
MVI B, 03H    ; Load 03H into register B
ADD B         ; A = A + B (Result = 08H)
HLT           ; Stop execution
END
```

---

### Common Instruction Types in 8085

| Instruction Type  | Examples                | Description                        |
| ----------------- | ----------------------- | ---------------------------------- |
| **Data Transfer** | MOV, MVI, LXI, STA, LDA | Move data between registers/memory |
| **Arithmetic**    | ADD, SUB, INR, DCR, ADC | Perform arithmetic                 |
| **Logical**       | ANA, ORA, XRA, CMP      | Perform logic operations           |
| **Branching**     | JMP, JNZ, JC, CALL, RET | Change program flow                |
| **Control**       | NOP, HLT, DI, EI        | Control processor operation        |

---

### Addressing Modes

Tell how the operand is specified in instruction.

| Mode                  | Example    | Meaning                           |
| --------------------- | ---------- | --------------------------------- |
| **Immediate**         | MVI A, 32H | Operand is in instruction         |
| **Register**          | MOV A, B   | Operand in register               |
| **Direct**            | LDA 2500H  | Memory address specified directly |
| **Register Indirect** | MOV A, M   | Operand in memory pointed by HL   |
| **Implicit**          | CMA        | Operand implied by instruction    |

---

### Flags in 8085

| Flag           | Meaning           | Set when                  |
| -------------- | ----------------- | ------------------------- |
| Z (Zero)       | Result = 0        | Result of operation is 0  |
| S (Sign)       | Negative result   | MSB = 1                   |
| P (Parity)     | Even number of 1s | Even parity               |
| CY (Carry)     | Carry/borrow      | Overflow/borrow           |
| AC (Aux Carry) | Between nibbles   | Carry from bit 3 to bit 4 |

---

### Example: Simple Addition Program

**Program to Add Two 8-bit Numbers**

```
MVI A, 25H
MVI B, 15H
ADD B
STA 2500H
HLT
```

Result (3AH) stored in memory location 2500H.

---

### Key Points to Remember

- **Opcode** = operation (e.g., ADD)
- **Operand** = data/register/memory (e.g., B, 25H)
- Each instruction executes in **machine cycles and T-states**.
- NEC exams often ask conceptual questions like:

  - “Which register holds the next instruction address?” → _Program Counter_
  - “Which instruction halts the processor?” → _HLT_
  - “What is the function of the accumulator?” → _Stores arithmetic and logical results_

### Sample NEC-style MCQs

1. **Which of the following is not a part of the microprocessor?**<br>
   a) ALU<br>
   b) Control Unit <br>
   c) Memory<br>
   d) Register<br><br>
   **Answer:** c) Memory (Memory is external to the processor)

2. **In 8085, how many address lines are available?**<br>
   a) 8<br>
   b) 16<br>
   c) 20<br>
   d) 32<br>
   <br>
   **Answer:** b) 16

3. **Instruction “MVI A, 09H” belongs to which addressing mode?**<br>
   a) Register<br>
   b) Immediate<br>
   c) Direct<br>
   d) Register Indirect<br><br>
   **Answer:** b) Immediate

4. **Which register holds the address of next instruction to be executed?**<br>
   **Answer:** Program Counter (PC)

5. **The result of an arithmetic operation is stored in:**<br>
   **Answer:** Accumulator
