## 1. Memory Device Classification and Hierarchy

### Classification by Type

| Memory Type               | Example                | Description                          |
| ------------------------- | ---------------------- | ------------------------------------ |
| **Primary (Main) Memory** | RAM, ROM               | Directly accessed by CPU             |
| **Secondary Memory**      | Hard disk, SSD         | Non-volatile, large storage          |
| **Cache Memory**          | L1, L2                 | Small, fast memory between CPU & RAM |
| **Virtual Memory**        | Disk space used as RAM | Managed by OS for large programs     |

---

### Memory Hierarchy (Fastest → Slowest)

```
Registers → Cache → Main Memory (RAM) → Secondary Storage (Disk)
```

> Higher level = faster access, smaller size, higher cost.

---

### Memory Based on Access

| Type                           | Meaning                      | Example                  |
| ------------------------------ | ---------------------------- | ------------------------ |
| **RAM (Random Access Memory)** | Read/write, volatile         | DRAM, SRAM               |
| **ROM (Read-Only Memory)**     | Non-volatile, permanent data | BIOS, firmware           |
| **EPROM**                      | Erasable by UV light         | Can be rewritten         |
| **EEPROM**                     | Electrically erasable        | Used in microcontrollers |
| **Flash Memory**               | Fast, rewritable             | Pen drives, SSDs         |

---

### Word Size and Addressing

- **Word size** = number of bits processed at once (e.g., 8-bit, 16-bit).
- **Address range** = determined by address bus width.

  - Example: 8085 → 16-bit address bus → 2¹⁶ = 65,536 bytes (64 KB).

## 2. Interfacing I/O and Memory

### What is Interfacing?

It is the **linking of external devices** (memory or I/O devices) with the microprocessor so they can **exchange data**.

---

### Types of Interfacing

1. **Memory Interfacing**

   - Connecting external RAM/ROM with the processor.
   - Uses **address**, **data**, and **control** buses.
   - Control signals used: `MEMR` (Memory Read), `MEMW` (Memory Write).

2. **I/O Interfacing**

   - Connecting input/output devices (keyboard, display, etc.).
   - Control signals: `IOR` (I/O Read), `IOW` (I/O Write).

---

### Addressing Methods

| Method                         | Range         | Example                                   |
| ------------------------------ | ------------- | ----------------------------------------- |
| **Memory-Mapped I/O**          | 64 KB         | Treated as part of memory; uses MEMR/MEMW |
| **Isolated I/O (Port-Mapped)** | 256 I/O ports | Uses IOR/IOW signals                      |

> _Exam Tip:_<br>
> “In memory-mapped I/O, which control signals are used?”<br>
> → **MEMR and MEMW**

## 3. Programmable Peripheral Interface (PPI – Intel 8255)

### Purpose

8255 PPI is used to **interface parallel I/O devices** (keyboards, LEDs, printers) with the microprocessor.

---

### Structure of 8255

- **3 Ports:**

  - **Port A (PA0–PA7)**
  - **Port B (PB0–PB7)**
  - **Port C (PC0–PC7)** (split into upper PC4–PC7 and lower PC0–PC3)

Each port can be **input or output**, depending on control word.

---

### Modes of Operation

| Mode                          | Description                                    |
| ----------------------------- | ---------------------------------------------- |
| **Mode 0:** Simple I/O        | Each port works independently as input/output. |
| **Mode 1:** Handshake I/O     | Used when CPU and device need synchronization. |
| **Mode 2:** Bidirectional I/O | Port A can send and receive data both ways.    |

---

### Control Word Register

- Used to **configure** the ports.
- Bit pattern defines direction (input/output) and mode.

Example control word:

```
D7 D6 D5 D4 D3 D2 D1 D0
1  0  0  0  1  0  0  0
```

Configures ports accordingly.

> Common Question:<br> > _“Which IC provides parallel I/O interfacing in microprocessor systems?”_<br> > **Answer:** 8255 PPI

## 4. Serial Interface

### Definition

In a **serial interface**, data is transferred **bit by bit** through a single communication line.

Opposite of **parallel interface**, where multiple bits travel simultaneously.

---

### Advantages

- Requires fewer wires.
- Cheaper and easier for long-distance communication.

### Examples

- **UART (Universal Asynchronous Receiver/Transmitter)**
- **USART (Universal Synchronous/Asynchronous Receiver/Transmitter)**
- **RS-232, SPI, I²C** standards.

---

## 5. Synchronous and Asynchronous Transmission

| Type             | Description                                            | Example      |
| ---------------- | ------------------------------------------------------ | ------------ |
| **Synchronous**  | Data sent continuously with **clock synchronization**  | SPI, I²C     |
| **Asynchronous** | Each byte sent independently, with **start/stop bits** | RS-232, UART |

### Key Difference

- **Synchronous:** sender + receiver share same clock.
- **Asynchronous:** no shared clock; uses start and stop bits to mark data boundaries.

---

## 6. Serial Interface Standards

| Standard                              | Description                                    | Typical Use                |
| ------------------------------------- | ---------------------------------------------- | -------------------------- |
| **RS-232**                            | Oldest standard, ±12 V signals, short distance | PC serial port             |
| **RS-422 / RS-485**                   | Differential signaling, long-distance          | Industrial networks        |
| **USB (Universal Serial Bus)**        | High-speed, plug-and-play serial               | Modern PCs                 |
| **I²C (Inter-Integrated Circuit)**    | Two-wire communication (SDA, SCL)              | Sensors, embedded systems  |
| **SPI (Serial Peripheral Interface)** | Four-wire full-duplex                          | Microcontrollers, displays |

## 7. Direct Memory Access (DMA) and DMA Controllers

### Concept

Normally, data transfer between memory and I/O happens **through CPU**, which can be slow.

**DMA (Direct Memory Access)** allows devices to transfer data **directly between memory and peripheral**, **bypassing the CPU**.

---

### Components

1. **DMA Controller (e.g., Intel 8257)**

   - Manages the transfer process.

2. **Memory and I/O Devices**

   - Source and destination of data.

---

### Working Steps

1. Device sends **DMA request** to CPU.
2. CPU **acknowledges and releases control** of buses.
3. DMA controller handles the data transfer directly.
4. After completion, control returns to CPU.

---

### Advantages

- Faster data transfer.
- Frees CPU for other tasks.
- Common in disk, sound, and network operations.

---

### Sample NEC-Style MCQs

1. **Which IC provides parallel I/O interfacing with a microprocessor?**<br>
   a) 8253 b) 8255 c) 8259 d) 8237<br>
   **Answer:** b) 8255

2. **In serial communication, data is transferred:**<br>
   a) Byte by byte b) Word by word c) Bit by bit d) Nibble by nibble<br>
   **Answer:** c) Bit by bit

3. **Which of the following uses handshaking signals?**<br>
   **Answer:** Mode 1 operation of 8255

4. **DMA transfers data between:**<br>
   **Answer:** Memory and I/O device directly (without CPU)

5. **In asynchronous transmission, synchronization is achieved by:**<br>
   **Answer:** Start and stop bits
