## Section 3.1 – Introduction to C Programming

### 1. What is C Programming?

- **C** is a **structured, procedural, high-level programming language** developed by **Dennis Ritchie** at **Bell Labs (1972)**.
- It’s often called **“the mother of all programming languages”** because most modern languages (like C++, Java, and Python) are influenced by it.
- C programs are **compiled**, not interpreted → meaning they’re converted into **machine code** by a compiler.

#### 🔹 Key features:

- Fast execution (close to hardware)
- Portable (works across platforms)
- Supports modular programming (functions)
- Low-level access (pointers, memory)

---

### 2. Basic Structure of a C Program

```c
#include <stdio.h>     // Preprocessor directive
int main() {           // Main function
    printf("Hello, World!");  // Statement
    return 0;          // Return value
}
```

#### 🔹 Explanation:

- `#include <stdio.h>` → includes standard input/output library
- `main()` → starting point of the program
- `printf()` → displays output
- `return 0;` → indicates successful program termination

---

### 3. C Tokens

**Tokens** are the smallest individual elements of a program.
There are **six types**:

| Type                    | Example               | Meaning                  |
| ----------------------- | --------------------- | ------------------------ |
| **Keywords**            | `int`, `if`, `return` | Reserved words           |
| **Identifiers**         | `age`, `sum`          | Programmer-defined names |
| **Constants**           | `10`, `3.14`, `'A'`   | Fixed values             |
| **Strings**             | `"Hello"`             | Sequence of characters   |
| **Operators**           | `+`, `==`, `&&`       | Perform operations       |
| **Punctuators/Symbols** | `;`, `{}`, `()`       | Structure symbols        |

**Exam Tip:** NEC loves to ask which of the following is a _keyword_ or _identifier_.

---

### 4. Operators in C

Operators perform operations on operands (variables or constants).

#### 🔹 Types of Operators:

| Type                      | Example                   | Description                      |                 |                    |
| ------------------------- | ------------------------- | -------------------------------- | --------------- | ------------------ |
| **Arithmetic**            | `+ - * / %`               | Basic math                       |                 |                    |
| **Relational**            | `== != > < >= <=`         | Compare values                   |                 |                    |
| **Logical**               | `&&                       |                                  | !`              | Combine conditions |
| **Assignment**            | `= += -= *= /=`           | Assign values                    |                 |                    |
| **Increment/Decrement**   | `++ --`                   | Increase or decrease value by 1  |                 |                    |
| **Bitwise**               | `&                        | ^ ~ << >>`                       | Operate on bits |                    |
| **Conditional (Ternary)** | `condition ? exp1 : exp2` | Short if-else                    |                 |                    |
| **Comma**                 | `,`                       | Separates expressions            |                 |                    |
| **sizeof()**              | `sizeof(int)`             | Returns memory size of data type |                 |                    |

**MCQ Example:**
What is the output of `printf("%d", 5/2);` → **Answer:** `2` (integer division)

---

### 5. Input/Output in C

#### 🔹 Formatted I/O Functions:

- **`printf()`** → for output
- **`scanf()`** → for input

Example:

```c
int a;
scanf("%d", &a);
printf("Value = %d", a);
```

- `%d` → integer
- `%f` → float
- `%c` → character
- `%s` → string

#### 🔹 Unformatted I/O Functions:

- **`getchar()`**, **`putchar()`** → read/write single character
- **`gets()`**, **`puts()`** → read/write string

⚠️ Note: `gets()` is unsafe → use `fgets()` instead.

**Exam Tip:**
Q: Which function reads a string until newline? → `gets()`
Q: Which is safer? → `fgets()`

---

### 6. Control Statements

Used to **control the flow** of execution.

#### 🔹 Types:

1. **Decision making:**

   - `if`, `if-else`, `nested if`, `switch`

2. **Looping (Iteration):**

   - `for`, `while`, `do-while`

3. **Jumping:**

   - `break`, `continue`, `goto`, `return`

Example:

```c
if (x > 0)
    printf("Positive");
else
    printf("Negative or Zero");
```

**MCQ Example:**
Which control statement is used to exit from a loop? → `break`

---

### 7. Looping Statements

| Loop         | Syntax                     | Description                             |
| ------------ | -------------------------- | --------------------------------------- |
| **for**      | `for(init; cond; update)`  | Used when number of iterations is known |
| **while**    | `while(condition)`         | Checks before executing                 |
| **do-while** | `do { } while(condition);` | Executes once even if condition false   |

Example:

```c
int i = 1;
do {
  printf("%d ", i);
  i++;
} while (i <= 5);
```

Output: `1 2 3 4 5`

**Exam Tip:**
Which loop executes at least once? → `do-while`

---

### 8. Functions in C

#### 🔹 Types:

- **Library Functions** → predefined (e.g., `printf()`, `sqrt()`)
- **User-defined Functions** → created by programmer

Syntax:

```c
return_type function_name(parameters) {
   // code
   return value;
}
```

#### Example:

```c
int add(int a, int b) {
   return a + b;
}
```

**MCQ Example:**
Which keyword is used to return a value from a function? → `return`

---

### 9. Recursive Functions

A function **calling itself** is recursive.

Example:

```c
int fact(int n) {
    if (n == 0) return 1;
    else return n * fact(n - 1);
}
```

**Exam Tip:**
Recursion must have a **base condition**, otherwise it leads to **infinite recursion**.

---

### 10. Arrays in C

#### 🔹 Types:

| Type                  | Example           | Description       |
| --------------------- | ----------------- | ----------------- |
| **1D Array**          | `int a[5];`       | Linear collection |
| **2D Array**          | `int a[3][3];`    | Matrix type       |
| **Multi-Dimensional** | `int a[2][3][4];` | Array of arrays   |

Access:

```c
a[0] = 10;
a[2][3] = 5;
```

**Exam Tip:**
Arrays are **stored in contiguous memory**.

---

### 11. String Manipulation

String = array of characters ending with `'\0'`.

```c
char name[10] = "Srijan";
```

#### Common Library Functions (`<string.h>`):

| Function                  | Description    |
| ------------------------- | -------------- |
| `strlen(s)`               | Returns length |
| `strcpy(dest, src)`       | Copy string    |
| `strcat(s1, s2)`          | Concatenate    |
| `strcmp(s1, s2)`          | Compare        |
| `strupr(s)` / `strlwr(s)` | Convert case   |

**MCQ Example:**
`strcmp("abc","abc")` → returns **0** (strings are equal)

### Sample NEC-style MCQs

1. Which of the following is not a C keyword?<br>
   A) static B) printf C) for D) return<br>
   **Answer:** B) printf<br>

2. The statement `for(;;)` in C means:<br>
   A) Infinite loop B) Syntax error C) Executes once D) Depends on condition<br>
   **Answer:** A) Infinite loop<br>

3. What will `printf("%d", 5%2);` print?<br>
   A) 0 B) 1 C) 2 D) 2.5<br>
   **Answer:** B) 1<br>

4. `strcmp("Nepal","Nepal")` returns:<br>
   A) 1 B) 0 C) -1 D) True<br>
   **Answer:** B) 0<br>

5. Which of the following executes at least once even if condition is false?<br>
   A) for B) while C) do-while D) if<br>
   **Answer:** C) do-while<br>
