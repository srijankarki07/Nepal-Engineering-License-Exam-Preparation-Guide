# **3.3 C++ Language Constructs with Objects and Classes**

## **1. Namespace**

Namespaces prevent name conflicts when using multiple libraries.

```cpp
#include <iostream>
using namespace std;
```

Or access like this:

```cpp
std::cout << "Hello";
```

🔹 **MCQ Points:**

- `std` is a namespace containing standard library features.
- Avoids naming conflicts.

---

## **2. Function Overloading**

Multiple functions can have the **same name** but **different parameter lists**.

```cpp
int add(int a, int b);
float add(float a, float b);
```

✔ Different parameter types or number.
✘ Return type alone cannot overload.

🔹 **MCQ Points:**

- Overloading is compile-time polymorphism.
- Must differ in **parameters**, not just return type.

---

## **3. Inline Function**

Used to reduce function call overhead by inserting function code at compile time.

```cpp
inline int square(int x) {
    return x * x;
}
```

🔹 **MCQ Points:**

- Inline is a _request_, not a command.
- Cannot use for recursion, loops, or large functions.
- Compiler may ignore inline.

---

## **4. Default Arguments**

Assign default values to function parameters.

```cpp
int sum(int a, int b = 10);
```

Called as:

```cpp
sum(5);      // uses b = 10
sum(5, 20);  // uses b = 20
```

🔹 **MCQ Points:**

- Default arguments must be assigned from **rightmost** side.
- Cannot skip middle default values.

---

## **5. Pass/Return by Reference**

Allows modifying actual variable.

### Pass by Reference:

```cpp
void update(int &x) {
    x = x + 1;
}
```

### Return by Reference:

```cpp
int& func(int &a) {
    return a;
}
```

🔹 **MCQ Points:**

- `&` in parameter = reference
- Avoids copying large data
- Faster and modifies actual variable

---

## **6. Introduction to Class and Object**

Class = blueprint
Object = instance

```cpp
class Student {
public:
    int id;
    string name;
};
```

Object:

```cpp
Student s1;
```

---

## **7. Access Specifiers**

| Specifier     | Access                |
| ------------- | --------------------- |
| **public**    | accessible everywhere |
| **private**   | inside class only     |
| **protected** | class + derived class |

🔹 **MCQ Points:**

- Default access in class → **private**
- Default access in struct → **public**

---

## **8. Objects and Member Access**

Access using dot operator:

```cpp
s1.id = 10;
s1.name = "Srijan";
```

---

## **9. Defining Member Functions**

### Inside class:

```cpp
class A {
public:
    void show() { cout << "Hello"; }
};
```

### Outside class:

```cpp
void A::show() {
    cout << "Hello";
}
```

---

## **10. Constructor and Its Types**

Constructor:

- same name as class
- no return type
- automatically called

### Types:

#### 1. Default Constructor

```cpp
A() { }
```

#### 2. Parameterized Constructor

```cpp
A(int x) { }
```

#### 3. Copy Constructor

```cpp
A(const A &obj) { }
```

#### 4. Dynamic Constructor

Allocates memory using `new`.

#### 5. Constructor Overloading

Multiple constructors with different parameters.

🔹 **MCQ Points:**

- Destructor has same name but starts with `~`.
- Copy constructor takes reference, never value.
- Constructors cannot be virtual.
- Constructors are not inherited.
- Destructor is called automatically when object goes out of scope.

---

## **11. Destructor**

```cpp
~A() { }
```

Tasks: free memory/resources.
Only **one** destructor allowed in class.
No parameters, no return type.

MCQ Tip: Destructor cannot be overloaded.

---

## **12. Dynamic Memory Allocation for Objects**

```cpp
Student *p = new Student;
p->id = 1;
delete p;
```

### Object array:

```cpp
Student *arr = new Student[5];
delete[] arr;
```

🔹 **MCQ Points:**

- Use `delete` for single object
- Use `delete[]` for arrays
- Memory leak occurs if delete is not used

---

## **13. this Pointer**

Points to the **current object**.

```cpp
this->x = x;
```

Useful when local and member variables have same name.

🔹 **MCQ Points:**

- Inside non-static member functions only
- Stores address of calling object
- Not available in static functions

---

## **14. Static Data Member**

Shared among all objects.

```cpp
class A {
public:
    static int count;
};
int A::count = 0;
```

---

## **15. Static Member Function**

```cpp
static void display() { }
```

🔹 **Features:**

- Can access **only static members**
- Called using class name: `A::display()`

---

## **16. Constant Member Functions and Constant Objects**

### Constant Function

```cpp
void show() const {
    // cannot modify member variables
}
```

### Constant Object

```cpp
const A obj;
```

- Can only call **const member functions**.

---

## **17. Friend Function and Friend Classes**

Friend function:

```cpp
class A {
private:
    int x;
    friend void show(A);
};
```

Friend class:

```cpp
class B {
public:
    void display(A);
};
```

🔹 **MCQ Points:**

- Friend breaks encapsulation
- Friend is **not inherited**
- Friend functions are not member functions
- Called normally, not with object

---
