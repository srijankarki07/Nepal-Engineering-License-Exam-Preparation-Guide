# **Section 3.4 — Features of Object-Oriented Programming**

## **1. Operator Overloading**

Operator overloading allows operators like `+`, `-`, `==`, etc. to work with user-defined types (objects).

### **Two ways to overload:**

#### Member function

```cpp
Complex operator+(Complex c);
```

#### Friend function

```cpp
friend Complex operator+(Complex a, Complex b);
```

---

### **Unary Operator Overloading**

Operators that work on a single operand (object):
Examples: `++`, `--`, `!`, `-` (unary minus)

##### Example:

```cpp
class A {
    int x;
public:
    void operator++() { x++; }
};
```

---

### **Binary Operator Overloading**

Operators with two operands:
Examples: `+`, `-`, `*`, `/`, `==`

##### Example:

```cpp
A operator+(A &obj) {
    A temp;
    temp.x = x + obj.x;
    return temp;
}
```

---

### Operators that CANNOT be overloaded:

- `.` (dot)
- `::` (scope resolution)
- `?:` (ternary)
- `sizeof`
- `typeid`

---

## **2. Data Conversion**

C++ supports converting between:

- **Basic type → Class type**
- **Class type → Basic type**
- **Class type → Class type**

### Basic → Class (using constructor)

```cpp
Number(int x) { num = x; }
```

### Class → Basic (using operator function)

```cpp
operator int() { return num; }
```

### Class → Class

Using conversion constructor OR conversion operator.

---

## **3. Inheritance**

Inheritance allows a class to acquire properties and behavior of another class.

---

### **Types of Inheritance**

#### **1. Single Inheritance**

One base → one derived

```
A → B
```

#### **2. Multiple Inheritance**

One derived class inherits from multiple base classes

```
 A   B
  \ /
   C
```

#### **3. Multilevel Inheritance**

Chain form

```
A → B → C
```

#### **4. Hierarchical Inheritance**

One base — multiple derived

```
  A
 / \
B   C
```

#### **5. Hybrid Inheritance**

Combination of two or more types.

Example: Hierarchical + Multiple.

---

## **Multipath Inheritance**

A special case of hybrid inheritance:

```
    A
   / \
  B   C
   \ /
    D
```

Problem: Ambiguity due to duplicate copy of base class A.

### Solution → **Virtual Base Class**

```
class B : virtual public A {};
class C : virtual public A {};
```

---

## **4. Constructor and Destructor in Inheritance**

### **Constructor Call Order**

**Base → Derived**

Example for single inheritance:

```
A() → B()
```

For multilevel:

```
A() → B() → C()
```

For multiple inheritance:

```
Base1() → Base2() → Derived()
```

(order in class declaration)

---

## **Destructor Call Order**

**Reverse of constructor order**

Example:

```
Derived → Base
```

---

### **Virtual Base Class Constructor Order**

Virtual base classes are initialized **first**, then normal base classes, then derived.
