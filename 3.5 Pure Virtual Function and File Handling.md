# **Section 3.5 — Pure Virtual Function and File Handling**

## **1. Virtual Functions**

### **Definition:**

A **virtual function** is a member function in the **base class** that can be **overridden in derived class**, allowing **dynamic (run-time) polymorphism**.

```cpp
class Base {
public:
    virtual void show() {
        cout << "Base class";
    }
};

class Derived : public Base {
public:
    void show() {
        cout << "Derived class";
    }
};

Base *b;
Derived d;
b = &d;
b->show();  // Output: Derived class
```

> **Key Point:** Virtual functions are resolved **at runtime**.

---

## **2. Pure Virtual Functions**

### **Definition:**

A function with `=0` in declaration is a **pure virtual function**.
Makes class **abstract** (cannot create object).

```cpp
class Base {
public:
    virtual void display() = 0; // pure virtual
};
```

### **Derived Class**

Must **override** pure virtual function, otherwise derived class is also abstract.

```cpp
class Derived : public Base {
public:
    void display() {
        cout << "Implemented";
    }
};
```

> **MCQ Tip:** Pure virtual function → abstract class → cannot create object.

---

## **3. Dynamic Binding**

- Virtual function → **runtime (dynamic) binding**
- Non-virtual function → **compile-time (static) binding**

> **Important:** Virtual functions use **vtable** mechanism behind the scenes.

---

## **4. File Handling in C++**

C++ uses **streams** to handle files:

- Input stream → `ifstream`
- Output stream → `ofstream`
- Both → `fstream`

```cpp
#include <fstream>
using namespace std;

ofstream fout("file.txt"); // write
ifstream fin("file.txt");  // read
```

---

### **5. Opening and Closing a File**

```cpp
ofstream fout;
fout.open("data.txt");    // open file
fout.close();             // close file
```

---

### **6. Input/Output Operations**

#### **Unformatted I/O**

- Character-level: `get()`, `put()`, `read()`, `write()`

```cpp
char ch;
fin.get(ch);
fout.put(ch);
```

#### **Formatted I/O**

- Using `<<` and `>>` operators

```cpp
int x;
fin >> x;
fout << x;
```

- Using `ios` flags and manipulators for formatting

```cpp
#include <iomanip>
fout << setw(10) << x;  // width 10
```

---

## **7. Error Handling during File I/O**

- Check if file opened successfully:

```cpp
ifstream fin("data.txt");
if (!fin) {
    cout << "Error opening file!";
}
```

- Flags:

```cpp
ios::in, ios::out, ios::app, ios::binary
```

---

## **8. Stream Class Hierarchy**

| Class    | Purpose                        |
| -------- | ------------------------------ |
| ios      | Base for all I/O streams       |
| istream  | Input stream (cin, ifstream)   |
| ostream  | Output stream (cout, ofstream) |
| iostream | Input + Output (cin/cout)      |

---

## **9. Formatted Input/Output with Manipulators**

Common manipulators:

| Manipulator       | Purpose               |
| ----------------- | --------------------- |
| `setw(n)`         | Width of output field |
| `setprecision(n)` | Decimal precision     |
| `left`, `right`   | Alignment             |
| `fixed`           | Fixed-point notation  |
| `scientific`      | Scientific notation   |

```cpp
cout << setw(10) << num;
cout << fixed << setprecision(2) << value;
```

---

## **10. Key MCQ Points**

- Virtual → runtime polymorphism
- Pure virtual → abstract class → cannot instantiate
- Virtual function resolved using **vtable**
- File streams: `ifstream`, `ofstream`, `fstream`
- Check **file open error** with `if(!file)`
- Formatted I/O uses **manipulators**
- Unformatted I/O uses `read()`, `write()`, `get()`, `put()`
