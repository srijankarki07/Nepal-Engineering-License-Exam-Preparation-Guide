# **Section 3.6 — Generic Programming and Exception Handling**

## **1. Function Template**

A **function template** allows writing **generic functions** that work with **any data type**.

```cpp
template <typename T>
T add(T a, T b) {
    return a + b;
}

int main() {
    cout << add<int>(5, 3);      // 8
    cout << add<float>(5.5, 2.2); // 7.7
}
```

- `T` is a placeholder type.
- The compiler generates a **specific version** for each type used.

---

## **2. Overloading Function Template**

You can overload templates just like normal functions.

```cpp
template <typename T>
T multiply(T a, T b) { return a*b; }

int multiply(int a, int b) { return a*b + 1; } // overload
```

---

## **3. Class Template**

Generic classes allow objects to handle **any data type**.

```cpp
template <class T>
class Box {
    T length;
public:
    Box(T l) { length = l; }
    T getLength() { return length; }
};
```

Usage:

```cpp
Box<int> b1(5);
Box<float> b2(5.5);
```

---

## **4. Function Definition of Class Template**

```cpp
template <class T>
T Box<T>::getLength() { return length; }
```

- Use `Box<T>` when defining member functions **outside the class**.

---

## **5. Standard Template Library (STL)**

STL contains **generic classes and functions** for data management.

### **Main components:**

1. **Containers** — store data

   - `vector`, `list`, `deque`, `set`, `map`, `stack`, `queue`

2. **Algorithms** — operate on containers

   - `sort()`, `reverse()`, `find()`

3. **Iterators** — access container elements

   - `begin()`, `end()`

### Example:

```cpp
#include <vector>
#include <algorithm>
using namespace std;

vector<int> v = {5, 3, 1};
sort(v.begin(), v.end()); // 1, 3, 5
```

---

## **6. Exception Handling Constructs**

C++ handles **runtime errors** using `try`, `catch`, and `throw`.

```cpp
try {
    int x = 0;
    if(x == 0) throw x;
} catch(int e) {
    cout << "Division by zero: " << e;
}
```

---

## **7. Multiple Exception Handling**

Multiple `catch` blocks can handle different types.

```cpp
try { ... }
catch(int e) { ... }
catch(char c) { ... }
catch(...) { cout << "Other exception"; } // catch all
```

---

## **8. Rethrowing Exception**

You can **rethrow an exception** for higher-level handling.

```cpp
catch(int e) {
    cout << "Caught, rethrowing...";
    throw;
}
```

---

## **9. Exception with Arguments**

```cpp
class MyException {
    string msg;
public:
    MyException(string m) { msg = m; }
    string what() { return msg; }
};

throw MyException("Error occurred");
```

---

## **10. Exception Specification for Function**

(Optional in modern C++ — deprecated)
Indicates exceptions a function may throw:

```cpp
void func() throw(int, char);
```

---

## **11. Handling Uncaught / Unexpected Exceptions**

- **Unexpected exception** → function called `unexpected()`
- **Uncaught exception** → program calls `terminate()`

> Usually handled by default, but can be customized.
