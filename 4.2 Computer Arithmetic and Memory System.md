## **4.2 Computer Arithmetic and Memory System**

This section deals with **how arithmetic operations are performed in hardware** and how **memory is organized, accessed, and optimized** for performance.

### **Computer Arithmetic**

#### Arithmetic and Logical Operations

Performed by the **Arithmetic Logic Unit (ALU)**.

**Common operations:**

- **Addition/Subtraction:** Binary addition using half adders/full adders.
- **Multiplication:** Repeated addition method or hardware multiplier.
- **Division:** Repeated subtraction or restoring/non-restoring algorithms.
- **Logical operations:** AND, OR, NOT, XOR, etc.

**Example:** <br>
1 + 1 = 10 (binary) → carry generated.<br>
ALU handles carry, overflow, zero flags, etc.

**MCQ Tip:**

- Overflow occurs when **carry into MSB ≠ carry out of MSB**.
- Logical operations work **bitwise**.

---

### **Memory System**

#### Memory Hierarchy

Memory is organized in a hierarchy to balance **speed**, **cost**, and **capacity**.

| Level | Example                    | Speed     | Cost     | Capacity |
| ----- | -------------------------- | --------- | -------- | -------- |
| 1     | Registers                  | Fastest   | Highest  | Smallest |
| 2     | Cache                      | Very Fast | High     | Small    |
| 3     | Main Memory (RAM)          | Medium    | Moderate | Medium   |
| 4     | Secondary Memory (SSD/HDD) | Slow      | Low      | Large    |

**MCQ Tip:**<br>
“Memory hierarchy” is used to **bridge the speed gap between CPU and memory.**

---

### **Internal and External Memory**

| Type     | Description                | Examples                                  |
| -------- | -------------------------- | ----------------------------------------- |
| Internal | Inside the computer or CPU | Register, Cache, Main memory              |
| External | Outside the CPU            | Magnetic disk, Optical disk, Flash drives |

**MCQ Tip:**

- Cache is **internal**,
- Hard disk is **external**.

---

### **Cache Memory Principles**

Cache memory = **small, high-speed memory** between CPU and main memory.
It stores **frequently accessed data** for faster retrieval.

**Working Principle:**

- When CPU needs data → checks cache first (called **cache hit**).
- If not found → fetch from main memory (**cache miss**).

  **MCQ Tip:**

- Cache improves **access time**, not **capacity**.
- **Locality of reference** = programs tend to access same data repeatedly.

---

### **Elements of Cache Design**

#### 1. **Cache Size**

- Larger cache → higher hit rate but more expensive.
- Typical size: few KBs to MBs.

#### 2. **Mapping Function**

Decides **how main memory blocks are placed in cache**.

| Type                    | Description                             |
| ----------------------- | --------------------------------------- |
| Direct Mapping          | One memory block → One fixed cache line |
| Associative Mapping     | Any memory block → Any cache line       |
| Set-Associative Mapping | Hybrid (divided into sets)              |

**MCQ Tip:**

- Direct mapping is **simple** but causes **conflicts**.
- Associative mapping gives **flexibility**.

---

#### 3. **Replacement Algorithm**

When cache is full, which block to replace?

| Algorithm | Meaning                     |
| --------- | --------------------------- |
| FIFO      | Replace oldest block        |
| LRU       | Replace Least Recently Used |
| Random    | Replace random block        |

**MCQ Tip:**<br>
Most used → **LRU (Least Recently Used)**

---

#### 4. **Write Policy**

Determines how writes are handled.

| Type          | Description                                             |
| ------------- | ------------------------------------------------------- |
| Write-through | Data written to cache **and** memory simultaneously     |
| Write-back    | Data written only to cache, updated to memory **later** |

**MCQ Tip:**

- Write-back → faster
- Write-through → safer (always updated)

---

#### 5. **Number of Caches**

Modern CPUs can have **multiple levels**:

- L1 (fastest, smallest)
- L2 (larger, slower)
- L3 (shared among cores)

  **MCQ Tip:**<br>
  L1 cache → built inside CPU core.

---

### **Memory Write Ability and Storage Permanence**

| Type         | Description               | Example         |
| ------------ | ------------------------- | --------------- |
| Volatile     | Loses data when power off | RAM             |
| Non-volatile | Retains data              | ROM, Flash, HDD |

**MCQ Tip:**

- RAM → volatile
- ROM → non-volatile

---

### **Composing Memory**

Combining multiple smaller memory units to create **larger memory**.

**Two ways:**

1. **Bit-level interleaving:** Combine for wider data word.
2. **Address-level interleaving:** Increase speed by accessing alternate memory modules simultaneously.

**MCQ Tip:**

- Interleaved memory → improves **throughput**.

---

### **Quick Summary of Section 4.2**

| Concept               | Key Point                         |
| --------------------- | --------------------------------- |
| ALU                   | Performs arithmetic and logic     |
| Memory Hierarchy      | Balances speed, cost, and size    |
| Cache                 | High-speed buffer memory          |
| Mapping Function      | Controls how memory maps to cache |
| Replacement Algorithm | Decides which block to replace    |
| Write Policy          | Controls write operation          |
| Volatile Memory       | Loses data on power off           |

## **MCQs**

**1.** The ALU performs which of the following operations?<br>
A. Data transfer<br>
B. Arithmetic and logic<br>
C. Input/Output<br>
D. Control sequencing<br>
**Answer:** B — Arithmetic and logic operations.

---

**2.** Overflow in binary addition occurs when:<br>
A. All bits are zero<br>
B. Carry out of MSB ≠ carry into MSB<br>
C. Carry out of LSB ≠ carry into LSB<br>
D. Operand signs are different<br>
**Answer:** B

---

**3.** Which of the following is the fastest type of memory?<br>
A. Main memory<br>
B. Cache memory<br>
C. Secondary storage<br>
D. Virtual memory<br>
**Answer:** B — Cache is the fastest accessible memory after registers.

---

**4.** The principle of cache memory is based on:<br>
A. Locality of reference<br>
B. Sequential access<br>
C. Associativity<br>
D. Hierarchical addressing<br>
**Answer:** A — Temporal and spatial locality.

---

**5.** In direct mapping of cache:<br>
A. A block can go anywhere in cache<br>
B. A block has one fixed location in cache<br>
C. Any block can go to any set<br>
D. None of these<br>
**Answer:** B

---

**6.** The least recently used (LRU) replacement algorithm replaces:<br>
A. The newest block<br>
B. The most recently used block<br>
C. The least recently used block<br>
D. Random block<br>
**Answer:** C

---

**7.** Which write policy updates both cache and memory simultaneously?<br>
A. Write-back<br>
B. Write-through<br>
C. Write-around<br>
D. Copy-back<br>
**Answer:** B — Write-through updates both cache and main memory.

---

**8.** ROM is an example of:<br>
A. Volatile memory<br>
B. Non-volatile memory<br>
C. Random access memory<br>
D. Cache memory<br>
**Answer:** B

---

**9.** Memory hierarchy is used to:<br>
A. Reduce CPU cost<br>
B. Match memory speed with CPU speed<br>
C. Increase secondary storage<br>
D. Reduce cache size<br>
**Answer:** B

---

**10.** Interleaved memory improves:<br>
A. Memory capacity<br>
B. Memory throughput (speed)<br>
C. Memory cost<br>
D. Memory retention<br>
**Answer:** B — Interleaving increases speed by parallel access.
