## Input–Output Organization and Multiprocessor\*\*

### **1. Peripheral Devices**

**Definition:**
Peripheral devices are **external devices** that provide **input or output** to the computer.

| Type            | Examples                 |
| --------------- | ------------------------ |
| Input devices   | Keyboard, Mouse, Scanner |
| Output devices  | Monitor, Printer         |
| Storage devices | Hard Disk, Pen Drive     |

Each peripheral connects to the **I/O subsystem** through an **I/O interface**.

**MCQ Tip:**
Peripheral devices are **not directly connected** to CPU; they communicate via I/O modules.

---

### **2. I/O Modules**

**I/O Module (or I/O Controller)** acts as a **bridge between CPU and peripheral devices.**

**Main functions:**

- Interface with CPU and device
- Data buffering (to match speed)
- Device control (start, stop, status)
- Interrupt handling

  **MCQ Tip:**
  I/O module synchronizes **fast CPU** with **slow peripherals.**

---

### 🔌 **3. Input–Output Interface**

Since CPU and peripherals operate differently (speed, data size, timing), an **interface circuit** is needed.

**I/O interface** includes:

- Data register (for data transfer)
- Status/control register (for device control)
- Control logic (to manage signals)

  **MCQ Tip:**

- Data register → stores data being transferred.
- Status register → stores device state (ready, busy, etc.).

---

### 🔁 **4. Modes of Data Transfer**

There are three main I/O transfer modes:

| Mode                           | Description                                                       |
| ------------------------------ | ----------------------------------------------------------------- |
| **Programmed I/O**             | CPU actively waits for I/O to complete. (Busy-waiting)            |
| **Interrupt-driven I/O**       | CPU does other tasks; device sends interrupt when ready.          |
| **Direct Memory Access (DMA)** | Device transfers data directly to memory without CPU involvement. |

**MCQ Tip:**

- Fastest: **DMA**
- CPU most involved: **Programmed I/O**

---

### ⚡ **5. Direct Memory Access (DMA)**

**DMA Controller (DMAC)** handles data transfer between **I/O device and memory directly**, bypassing CPU.

**Steps:**

1. CPU sets up DMA (source, destination, count)
2. DMA transfers data
3. Sends interrupt to CPU when done

**MCQ Tip:**
DMA reduces **CPU overhead** in data transfer.

---

### 🧠 **6. Characteristics of Multiprocessors**

A **multiprocessor system** contains **two or more CPUs** sharing memory and I/O.

**Key features:**

- Shared main memory
- Common clock
- Interconnected CPUs
- Coordination through OS

  **Advantages:**

- Increased performance
- Reliability (failure in one CPU doesn’t stop system)

  **MCQ Tip:**
  Multiprocessor → multiple **CPUs** sharing **common memory**.

---

### 🔗 **7. Interconnection Structure**

Refers to how processors, memory, and I/O modules are connected.

**Common structures:**

- **Bus interconnection:** Shared communication path
- **Crossbar switch:** Multiple parallel connections
- **Multistage network:** Combination of switches

  **MCQ Tip:**
  Bus is the **simplest** and most **common** interconnection method.

---

### 🤝 **8. Inter-Processor Communication and Synchronization**

When multiple CPUs work together:

- They need to **communicate** (share data)
- And **synchronize** (avoid conflicts)

**Mechanisms used:**

- Shared memory
- Message passing
- Semaphores and mutex locks

  **MCQ Tip:**
  Synchronization prevents **race conditions** (two CPUs writing same data simultaneously).

---

| Concept            | Key Point                          |
| ------------------ | ---------------------------------- |
| Peripheral Devices | External input/output units        |
| I/O Module         | Bridge between CPU and peripherals |
| I/O Interface      | Connects CPU with I/O              |
| Programmed I/O     | CPU waits for device               |
| DMA                | Direct memory-device transfer      |
| Multiprocessor     | Two or more CPUs sharing memory    |
| Interconnection    | Bus, crossbar, or multistage       |
| Synchronization    | Coordination between CPUs          |
