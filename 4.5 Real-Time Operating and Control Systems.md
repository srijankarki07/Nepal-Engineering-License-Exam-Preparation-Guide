## **4.5 Real-Time Operating and Control Systems**

### **1. Operating System Basics**

**Operating System (OS):** Software that manages hardware and software resources.

- Controls CPU, memory, I/O, and devices.
- In embedded systems, often **real-time OS (RTOS)** is used.

  **MCQ Tip:**

- RTOS ensures **timely execution of tasks**.
- Regular OS → no strict timing guarantee.

---

### **2. Task, Process, and Threads**

| Term    | Meaning                                                  |
| ------- | -------------------------------------------------------- |
| Task    | Smallest unit of work in RTOS                            |
| Process | Program in execution                                     |
| Thread  | Lightweight process, shares resources with other threads |

**MCQ Tip:**

- Task scheduling → CPU decides **which task to execute next**.

---

### **3. Multiprocessing and Multitasking**

- **Multiprocessing:** Multiple CPUs executing simultaneously.
- **Multitasking:** Single CPU switches between multiple tasks quickly (time-sharing).

  **MCQ Tip:**

- Embedded systems may use **multitasking RTOS** to manage multiple tasks efficiently.

---

### **4. Task Scheduling**

**Purpose:** Decide order and timing of tasks.

- **Scheduling policies:**

  - **Round Robin** – Equal time slices
  - **Priority-Based** – High-priority task runs first
  - **Earliest Deadline First** – Task with closest deadline runs first

  **MCQ Tip:**

- Hard real-time → priority and deadlines are critical.

---

### **5. Task Synchronization**

- Ensures tasks **don’t conflict** when accessing shared resources.
- Mechanisms:

  - **Semaphore** – Binary (0/1) lock
  - **Mutex** – Mutual exclusion
  - **Event flags** – Signal task status

  **MCQ Tip:**

- Synchronization prevents **race conditions** and data corruption.

---

### **6. Device Drivers**

- Software that **controls specific hardware devices**.
- Provides interface between **OS and peripherals**.
- Handles low-level I/O operations.

  **MCQ Tip:**

- Driver → allows tasks to **use devices without knowing hardware details**.

---

### **7. Open-loop and Closed-loop Control Systems**

| Type        | Description                                                              |
| ----------- | ------------------------------------------------------------------------ |
| Open-loop   | Output not fed back; no correction (e.g., washing machine timer)         |
| Closed-loop | Output measured and fed back to adjust input (e.g., temperature control) |

**MCQ Tip:**

- Closed-loop → also called **feedback control system**.
- Open-loop → simpler, no feedback.

---

### **Quick Summary of Section 4.5**

| Concept                      | Key Point                                |
| ---------------------------- | ---------------------------------------- |
| RTOS                         | Ensures real-time task execution         |
| Task/Process/Thread          | Units of work                            |
| Multiprocessing/Multitasking | Multiple CPUs vs single CPU time-sharing |
| Task Scheduling              | Determines execution order               |
| Task Synchronization         | Prevents resource conflicts              |
| Device Drivers               | Software-hardware interface              |
| Open/Closed Loop             | Feedback-based or not                    |

## **MCQs**

**1.** A real-time operating system (RTOS) ensures:<br>
A. Maximum throughput only<br>
B. Timely execution of tasks<br>
C. Unlimited memory usage<br>
D. Only background processes<br>
**Answer:** B — _Timing is critical in RTOS._

---

**2.** In embedded systems, a **task** is:<br>
A. A hardware component<br>
B. The smallest unit of work<br>
C. The operating system itself<br>
D. A peripheral device<br>
**Answer:** B

---

**3.** Multitasking refers to:<br>
A. Multiple CPUs executing simultaneously<br>
B. A single CPU switching between multiple tasks quickly<br>
C. A task running on multiple threads simultaneously<br>
D. None of the above<br>
**Answer:** B

---

**4.** Round-robin scheduling assigns:<br>
A. Tasks based on priority<br>
B. Tasks equal time slices<br>
C. Tasks randomly<br>
D. Tasks based on deadlines<br>
**Answer:** B

---

**5.** Semaphore and mutex are used for:<br>
A. Task scheduling<br>
B. Task synchronization<br>
C. Data storage<br>
D. Peripheral interfacing<br>
**Answer:** B — _They prevent resource conflicts._

---

**6.** A device driver:<br>
A. Schedules tasks<br>
B. Provides software interface to hardware<br>
C. Allocates memory<br>
D. Manages network traffic<br>
**Answer:** B

---

**7.** Open-loop control system:<br>
A. Uses feedback to correct output<br>
B. Does not use feedback<br>
C. Only works in software<br>
D. Only exists in hardware<br>
**Answer:** B

---

**8.** Closed-loop control system is also called:<br>
A. Feedforward system<br>
B. Feedback control system<br>
C. Sequential system<br>
D. Open-loop system<br>
**Answer:** B

---

**9.** Earliest deadline first (EDF) scheduling runs:<br>
A. Task with largest execution time<br>
B. Task with highest priority<br>
C. Task with closest deadline<br>
D. Tasks in random order<br>
**Answer:** C

---

**10.** Multiprocessing differs from multitasking because:<br>
A. Multiprocessing uses multiple CPUs, multitasking uses one CPU<br>
B. Multiprocessing uses one CPU, multitasking uses multiple CPUs<br>
C. Both are same<br>
D. Multiprocessing is only software-based<br>
**Answer:** A<br>
