### **Section 5.1 – Introduction to Computer Networks and Physical Layer**

## 1. Computer Network – Basic Concept

A **computer network** is a system of interconnected computers and devices that communicate and share resources (like data, printers, internet, etc.).

### Main Purpose:

- **Resource sharing** (hardware, software, data)
- **Communication** (email, chat)
- **File transfer**
- **Centralized data management**

### Types of Networks (based on area):

| Type | Full form                 | Coverage area     | Example          |
| ---- | ------------------------- | ----------------- | ---------------- |
| PAN  | Personal Area Network     | few meters        | Bluetooth, USB   |
| LAN  | Local Area Network        | within a building | Office network   |
| MAN  | Metropolitan Area Network | within a city     | Cable TV network |
| WAN  | Wide Area Network         | country/world     | Internet         |

---

## 2. Networking Models

### (a) **Centralized Model**

- One main computer (server) controls all.
- Example: Mainframe systems.

### (b) **Distributed Model**

- Tasks divided among multiple systems.
- Each computer (node) can process and share data.

### (c) **Client-Server Model**

- **Client** requests services.
- **Server** provides services (e.g., web server, mail server).

### (d) **Peer-to-Peer Model**

- No dedicated server.
- All computers act as both client and server.
- Example: Torrent file sharing.

---

## 3. Protocols and Standards

### Protocol:

A **set of rules** that govern data communication between network devices.

Examples:

- HTTP (Web)
- FTP (File Transfer)
- TCP/IP (Data transmission)
- SMTP (Email)
- DNS (Domain naming)

### Standard:

Defined by organizations to ensure compatibility and interoperability between devices.

**Standard organizations:**

| Organization | Role                           |
| ------------ | ------------------------------ |
| ISO          | OSI Model                      |
| IEEE         | LAN/MAN standards (802 series) |
| IETF         | Internet standards             |
| ITU          | Telecommunication standards    |

---

## 4. OSI and TCP/IP Model

### **OSI (Open Systems Interconnection) Model – 7 Layers**

| Layer           | Function                     | Example Protocols |
| --------------- | ---------------------------- | ----------------- |
| 7. Application  | User interface               | HTTP, FTP, SMTP   |
| 6. Presentation | Data translation, encryption | JPEG, SSL         |
| 5. Session      | Maintains sessions           | NetBIOS, RPC      |
| 4. Transport    | Reliable delivery            | TCP, UDP          |
| 3. Network      | Routing, addressing          | IP, ICMP          |
| 2. Data Link    | Framing, error control       | Ethernet, PPP     |
| 1. Physical     | Transmission of bits         | Cables, hubs      |

**Mnemonic:**

_All People Seem To Need Data Processing_

---

### **TCP/IP Model – 4 Layers**

| TCP/IP Layer   | Corresponding OSI Layers             | Example Protocols |
| -------------- | ------------------------------------ | ----------------- |
| Application    | Application + Presentation + Session | HTTP, FTP, DNS    |
| Transport      | Transport                            | TCP, UDP          |
| Internet       | Network                              | IP, ICMP          |
| Network Access | Data Link + Physical                 | Ethernet, PPP     |

**TCP/IP is the practical model** used on the Internet.<br>
**OSI is theoretical**, mainly for understanding.

---

## 5. Networking Devices

| Device     | OSI Layer           | Function                                                      |
| ---------- | ------------------- | ------------------------------------------------------------- |
| **Hub**    | Physical (Layer 1)  | Broadcasts data to all devices; no intelligence.              |
| **Bridge** | Data Link (Layer 2) | Connects 2 LAN segments, filters traffic by MAC address.      |
| **Switch** | Data Link (Layer 2) | Smart bridge; sends data only to the intended device.         |
| **Router** | Network (Layer 3)   | Routes packets between different networks using IP addresses. |

<br>

**Extra:**

- **Gateway** works at **all layers**, translating protocols (e.g., email to SMS).
- **Repeater** amplifies signals over long distances (Layer 1).

---

## 6. Transmission Media

### (a) **Guided Media (Wired)**

Signal travels through a physical medium.

| Type          | Features                                          | Example                 |
| ------------- | ------------------------------------------------- | ----------------------- |
| Twisted Pair  | Cheap, short distance                             | LAN cables (Cat5, Cat6) |
| Coaxial Cable | Better shielding                                  | TV cable, CCTV          |
| Optical Fiber | High speed, long distance, immune to interference | Internet backbone       |

### (b) **Unguided Media (Wireless)**

Signal transmitted through air.

| Type        | Range  | Example                        |
| ----------- | ------ | ------------------------------ |
| Radio Waves | Long   | FM radio, Wi-Fi                |
| Microwaves  | Medium | Cellular communication         |
| Infrared    | Short  | Remote control, wireless mouse |

---

## Quick Summary

- **OSI = 7 layers**, theoretical
- **TCP/IP = 4 layers**, practical
- **Hub** – broadcasts; **Switch** – selective; **Router** – routes between networks
- **Optical Fiber** = fastest medium
- **Standards**: IEEE, ISO, ITU
- **Protocols** = Rules for communication
