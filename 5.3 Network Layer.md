## **Section 5.3 – Network Layer**

### Overview

The **Network Layer** is the **3rd layer** in the OSI model.
It is responsible for **delivering packets** from the **source** to the **destination** possibly across **multiple networks**.

---

### Main Functions of Network Layer

| Function                         | Description                                                  |
| -------------------------------- | ------------------------------------------------------------ |
| **Logical Addressing**           | Uses **IP addresses** to identify devices across networks.   |
| **Routing**                      | Selects the **best path** for data to reach the destination. |
| **Fragmentation & Reassembly**   | Breaks large packets into smaller ones to fit MTU size.      |
| **Error Handling & Diagnostics** | Uses ICMP messages.                                          |

---

## 1. Addressing

There are two types of addresses:

- **Physical address (MAC)** → Data Link Layer (local)
- **Logical address (IP)** → Network Layer (global)

---

### Internet Address (IPv4)

IPv4 = **32-bit** address → represented in **4 octets** (e.g., 192.168.1.10)

Each part ranges from **0–255**, written in **dotted-decimal notation**.

---

### Classful Addressing (Old but still exam-relevant)

| Class | Range of 1st Octet | No. of Networks | Hosts per Network | Default Subnet Mask | Example     |
| ----- | ------------------ | --------------- | ----------------- | ------------------- | ----------- |
| A     | 0 – 127            | 128             | ~16 million       | 255.0.0.0           | 10.0.0.1    |
| B     | 128 – 191          | 16,384          | ~65,000           | 255.255.0.0         | 172.16.0.1  |
| C     | 192 – 223          | 2 million       | 254               | 255.255.255.0       | 192.168.1.1 |
| D     | 224 – 239          | Multicast       | —                 | —                   | 224.0.0.1   |
| E     | 240 – 255          | Experimental    | —                 | —                   | 240.1.0.1   |

_Remember:_

- **A → Big networks**
- **C → Small networks**
- **D → Multicast**
- **E → Experimental**

---

### Private IP Address Ranges

Used **inside organizations** (not routable on the Internet).

| Class | Private Range                 |
| ----- | ----------------------------- |
| A     | 10.0.0.0 – 10.255.255.255     |
| B     | 172.16.0.0 – 172.31.255.255   |
| C     | 192.168.0.0 – 192.168.255.255 |

---

### Subnetting (Key exam concept)

Subnetting = Dividing one network into smaller sub-networks.

**Why?**

- Efficient IP usage
- Better network management
- Enhanced security

#### Example:

Network: 192.168.1.0/24 <br>
Subnet mask: 255.255.255.0 → 256 addresses (0–255)

If we create 4 subnets → we borrow 2 bits (2² = 4).

New mask: **255.255.255.192 (/26)**<br>
Each subnet = 64 addresses<br>
→ 4 subnets:<br>
192.168.1.0, 192.168.1.64, 192.168.1.128, 192.168.1.192

**First address → Network ID**
**Last address → Broadcast ID**

_Quick formula:_

- No. of subnets = 2ⁿ (n = bits borrowed)
- No. of hosts per subnet = 2ʰ − 2 (h = remaining host bits)

## 2. Routing and Routing Protocols

### Routing

It is the process of **finding the best path** for a packet to travel from source to destination.

### Types of Routing

| Type                | Description                                               |
| ------------------- | --------------------------------------------------------- |
| **Static Routing**  | Manual configuration by admin. Simple but not flexible.   |
| **Dynamic Routing** | Routers share info automatically using routing protocols. |
| **Default Routing** | Used when path is unknown (like default gateway).         |

---

### Routing Algorithms

| Algorithm                      | Description                                                         |
| ------------------------------ | ------------------------------------------------------------------- |
| **Shortest Path (Dijkstra’s)** | Finds the shortest route (used in OSPF).                            |
| **Flooding**                   | Sends packets through all possible paths. Inefficient but reliable. |
| **Distance Vector**            | Routers share info with neighbors (used in RIP).                    |
| **Link State**                 | Routers know entire network topology (used in OSPF).                |

---

### Routing Protocols

| Protocol                               | Type     | Algorithm       | Description                                   |
| -------------------------------------- | -------- | --------------- | --------------------------------------------- |
| **RIP (Routing Information Protocol)** | Interior | Distance Vector | Uses hop count (max 15 hops)                  |
| **OSPF (Open Shortest Path First)**    | Interior | Link State      | Uses cost (bandwidth-based)                   |
| **BGP (Border Gateway Protocol)**      | Exterior | Path Vector     | Used between ISPs; Internet backbone protocol |

_Remember:_

- **RIP → small networks**
- **OSPF → large networks**
- **BGP → between organizations**

---

### Unicast vs Multicast Routing

| Type          | Meaning                      |
| ------------- | ---------------------------- |
| **Unicast**   | One-to-one communication     |
| **Multicast** | One-to-many (selected group) |
| **Broadcast** | One-to-all (same network)    |

---

## 3. Important Network Layer Protocols

| Protocol                                     | Purpose                                                      |
| -------------------------------------------- | ------------------------------------------------------------ |
| **IP (Internet Protocol)**                   | Provides addressing and routing of packets.                  |
| **ARP (Address Resolution Protocol)**        | Finds MAC address from IP (Layer 2 + 3 link).                |
| **RARP (Reverse ARP)**                       | Finds IP from MAC address.                                   |
| **ICMP (Internet Control Message Protocol)** | Error reporting and diagnostics (e.g., Ping uses ICMP Echo). |

---

## 4. IPv6 (Internet Protocol Version 6)

IPv6 was introduced to overcome the **limitations of IPv4**.

### Key Features

| Feature             | IPv4                               | IPv6                             |
| ------------------- | ---------------------------------- | -------------------------------- |
| Address length      | 32 bits                            | 128 bits                         |
| Address format      | Dotted decimal (e.g., 192.168.0.1) | Hexadecimal (e.g., 2001:0db8::1) |
| Number of addresses | ~4.3 billion                       | 3.4×10³⁸ (almost unlimited)      |
| Header size         | 20 bytes                           | 40 bytes (simplified)            |
| Security            | Optional                           | Built-in IPsec support           |
| Fragmentation       | By routers and hosts               | Only by hosts                    |

---

### IPv6 Packet Format

- **Main Header:** Version, Source, Destination, Traffic class, Payload length, Next header, Hop limit.
- **Extension Headers:** Used for options like routing, authentication, fragmentation, etc.

---

### IPv6 Transition Methods

1. **Dual Stack** – Devices run both IPv4 and IPv6 simultaneously.
2. **Tunneling** – IPv6 packets encapsulated inside IPv4.
3. **Translation** – IPv4 ↔ IPv6 conversion (NAT64).

---

### IPv6 Multicasting

- IPv6 replaces _broadcasting_ with **multicasting**.
- Reduces unnecessary network traffic.
