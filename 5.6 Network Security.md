# **5.6 Network Security**

Network security is about **protecting data**, **devices**, and **communication** from attacks, misuse, unauthorized access, and damage.

## 1. **Types of Computer Security**

There are **three main types**:

### **1. Network Security**

- Protects **network devices and data** during transmission.
- Handles firewalls, IDS/IPS, VPN, filtering, etc.

### **2. Information Security**

- Protects **data** from unauthorized access, modification, destruction.
- Involves encryption, authentication, authorization.

### **3. Cybersecurity**

- Protects systems from **cyber-attacks** (hackers, malware, DDoS).

---

## 2. **Types of Security Attacks**

Attacks are usually divided into **Active** and **Passive**.

## **Passive Attacks (Monitoring only)**

Attacker **does not modify** the data.

- **Eavesdropping / Snooping**
- **Traffic analysis**
- **Sniffing**

_Hard to detect but easy to prevent via encryption._

---

## **Active Attacks (Modify / interrupt data)**

Attacker **changes**, **injects**, or **deletes** data.

- **Masquerading** (pretending to be someone else)
- **Replay attack**
- **Modification of messages**
- **Denial of Service (DoS / DDoS)**
- **Man-in-the-Middle (MITM)**
- **Virus / Worms / Malware**

_Easier to detect but harder to prevent._

---

## 3. **Principles of Cryptography (CIA Triad)**

Every security mechanism is based on these three:

### **1. Confidentiality**

- Only authorized people should access data.
- Achieved by **encryption**.

### **2. Integrity**

- Data should **not be altered**.
- Achieved by **hashing**, **digital signatures**.

### **3. Availability**

- Resources should be available when needed.
- Achieved by **firewalls, redundancy, load balancing.**

---

## 4. **RSA Algorithm (Very Important MCQ Topic)**

RSA is an **asymmetric key encryption algorithm**.<br>
It uses **two keys: Public Key + Private Key**.

Public key is used for **encryption**<br>
Private key is used for **decryption**<br>

### Steps (simple version):

1. Choose two large prime numbers: **p** and **q**
2. Compute: **n = p × q**
3. Compute Euler’s totient: **φ(n) = (p – 1)(q – 1)**
4. Choose **public key e** (commonly 3, 17, or 65537)
5. Compute private key **d**, such that:

   ```
   e × d ≡ 1 (mod φ(n))
   ```

6. Public Key = (e, n)
7. Private Key = (d, n)

### MCQ fact:

RSA provides **confidentiality + authentication**.

---

## 5. **Digital Signatures**

Digital signature = **Hash + Encryption using private key**.

### How it works:

1. Sender creates a **hash** of the message.
2. Sender encrypts the hash using **private key** (this is the digital signature).
3. Receiver decrypts signature using **sender’s public key**.
4. If hash matches → message is authentic.

### Provides:

- **Authentication**
- **Integrity**
- **Non-repudiation** (sender cannot deny sending)

---

## 6. **Securing E-mail (PGP)**

**PGP ( Pretty Good Privacy)**<br>
Used to secure email by using **both symmetric and asymmetric** encryption.

### PGP uses:

- **Symmetric key** → for encrypting message
- **Asymmetric key** → for sending the symmetric key securely
- **Hash** → for integrity
- **Digital signature** → for authenticity

---

## 7. **Securing TCP Connections (SSL/TLS)**

**SSL – Secure Sockets Layer**
**TLS – Transport Layer Security (modern version)**
Used in **HTTPS**, online banking, logins, etc.

### SSL/TLS Provides:

Encryption<br>
Authentication<br>
Integrity

### Works through:

- **Handshake**
- **Server certificate**
- **Key exchange**
- **Session keys**

Port used by HTTPS (SSL/TLS): **443**

---

## 8. **Network Layer Security (IPsec)**

IPsec = **Internet Protocol Security**

Used for securing communication at the **Network Layer**.

### IPsec provides:

- **Confidentiality** (encryption)
- **Integrity** (hashing)
- **Authentication**
- **Anti-replay protection**

### Two modes:

1. **Transport Mode** – encrypts _only payload_
2. **Tunnel Mode** – encrypts _entire IP packet_ (used in VPN)

### Two main protocols:

- **AH (Authentication Header)** → provides integrity
- **ESP (Encapsulating Security Payload)** → provides encryption

---

## 9. **Virtual Private Network (VPN)**

VPN creates a **secure tunnel** through an insecure network (Internet).
Used to access private networks remotely.

### VPN provides:

- Encryption
- Privacy
- Secure remote access
- Masking IP addresses

Uses protocols like **IPsec**, **OpenVPN**, **L2TP**, **PPTP**, etc.

---

## 10. **Securing Wireless LANs (WEP)**

**WEP – Wired Equivalent Privacy**

Used in older WiFi security.

### Problems:

- Weak encryption (uses RC4)
- Vulnerable to attacks
- Replaced by **WPA** and **WPA2**

### MCQ fact:

WEP uses **RC4** encryption and **IV (Initialization Vector)**.

---

## 11. **Firewalls**

A firewall monitors and controls **incoming and outgoing traffic**.

### Types of Firewalls:

1. **Packet Filtering Firewall**

   - Checks IP, port.
   - Fast but less secure.

2. **Stateful Firewall**

   - Tracks connection state.
   - Most widely used.

3. **Application-Level Gateway (Proxy Firewall)**

   - Works on application layer.
   - Slow but very secure.

4. **NGFW (Next-Gen Firewall)**

   - Deep packet inspection
   - Malware filtering
   - Intrusion detection

### Firewall Functions:

- Block unauthorized access
- Allow legitimate traffic
- Enforce security policies
