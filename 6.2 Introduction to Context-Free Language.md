### **_Section 6.2 — Introduction to Context-Free Language (CFL)_**

---

### 1. What is a Context-Free Language (CFL)?

A **Context-Free Language (CFL)** is a language generated by a **Context-Free Grammar (CFG)**.

**In simple words:**
CFLs are languages that can be represented by rules where **a single non-terminal** on the left-hand side is replaced by **a string of terminals and/or non-terminals**.

Example:

```
S → aSb | ε
```

This grammar generates strings like:
`ab`, `aabb`, `aaabbb`, etc.<br>
→ All strings with equal number of a’s followed by equal number of b’s.<br>
It’s **not regular**, but it **is context-free**.

---

### 2. Context-Free Grammar (CFG)

A **CFG** is defined by a 4-tuple:

[
G = (V, T, P, S)
]

| Symbol | Meaning                                                    |
| :----- | :--------------------------------------------------------- |
| **V**  | Set of non-terminals (variables like S, A, B, …)           |
| **T**  | Set of terminals (actual input symbols like a, b, +, etc.) |
| **P**  | Set of productions (rules of form A → α)                   |
| **S**  | Start symbol (a variable from where derivation begins)     |

---

### 3. Derivations

A **derivation** shows how a string is produced from the start symbol using grammar rules.

Example Grammar:

```
S → aSb | ε
```

Derivation of “aabb”:

```
S → aSb → aaSbb → aabb
```

---

### 4. Types of Derivations

| Type                           | Description                                         |
| ------------------------------ | --------------------------------------------------- |
| **Leftmost Derivation (LMD)**  | Always expand the **leftmost** non-terminal first.  |
| **Rightmost Derivation (RMD)** | Always expand the **rightmost** non-terminal first. |

Both lead to the same final string, but derivation order differs.

---

### 5. Parse Tree (or Derivation Tree)

A **Parse Tree** visually represents how a grammar generates a string.

Example Grammar:

```
S → aSb | ε
```

String: `aabb`

Parse Tree:

```
      S
     /|\
    a S b
      /|\
     a S b
       |
       ε
```

The **leaves** of the tree (left to right) form the generated string.

---

### 6. Ambiguous Grammar

A grammar is **ambiguous** if there exists at least **one string** that can have **more than one parse tree**.

Example:

```
E → E + E | E * E | id
```

For string `id + id * id`,
two different parse trees are possible due to operator precedence confusion.
Such a grammar is **ambiguous**.

**Eliminating ambiguity:**
We can rewrite grammar to specify precedence clearly:

```
E → E + T | T
T → T * F | F
F → id
```

---

### 7. Normal Forms

Normal Forms are **standardized representations** of grammars helpful in simplification and algorithmic parsing.

#### (a) **Chomsky Normal Form (CNF)**

- All productions are of the form:

  - **A → BC** (where B and C are non-terminals)
  - **A → a** (a terminal)

- No ε-productions (except possibly for start symbol)
- No unit productions (A → B)

**Example:**

```
S → AB | a
A → a
B → b
```

#### (b) **Greibach Normal Form (GNF)**

- Productions are of the form:

  - **A → aα**, where **a** is a terminal and **α** is a (possibly empty) string of non-terminals.

**Example:**

```
S → aA | bB
A → a
B → b
```

#### (c) **Backus–Naur Form (BNF)**

A notation used in **programming language syntax** representation.

**Example (for arithmetic expression):**

```
<expr> ::= <expr> + <term> | <term>
<term> ::= <term> * <factor> | <factor>
<factor> ::= ( <expr> ) | id
```

---

### 8. Pushdown Automata (PDA)

To recognize **Context-Free Languages**, we use **Pushdown Automata (PDA)**.

**It’s like a Finite Automaton but with an extra memory stack.**

---

#### PDA Components:

A PDA is a 6-tuple:
[
M = (Q, Σ, Γ, δ, q₀, Z₀, F)
]

| Symbol | Meaning                                                                 |
| :----- | :---------------------------------------------------------------------- |
| **Q**  | Finite set of states                                                    |
| **Σ**  | Input alphabet                                                          |
| **Γ**  | Stack alphabet                                                          |
| **δ**  | Transition function (depends on current state, input, and top of stack) |
| **q₀** | Start state                                                             |
| **Z₀** | Initial stack symbol                                                    |
| **F**  | Set of accepting states                                                 |

---

#### PDA can accept by:

1. **Final State** (ending in an accepting state)
2. **Empty Stack** (when stack becomes empty after full processing)

---

### 9. Equivalence of Context-Free Language and PDA

**Every context-free language can be recognized by some PDA**,
and conversely, **For every PDA, there exists a CFG** generating the same language.

Hence, **PDA ≡ CFG**

---

### 10. Pumping Lemma for Context-Free Languages

Like the regular one — but used to show a language is **not context-free**.

**Statement:**
For every CFL **L**,
there exists a constant **p** such that any string **s ∈ L** with |s| ≥ p can be written as:

[
s = uvwxy
]

such that:

1. ( |vwx| ≤ p )
2. ( vx ≠ ε )
3. ( u v^i w x^i y ∈ L ) for all ( i ≥ 0 )

**Example (non-CFL):**
L = { aⁿbⁿcⁿ | n ≥ 0 }
Using Pumping Lemma, this language can be proven **not context-free**.

---

### 11. Properties of Context-Free Languages

| Property      | Closed Under | Not Closed Under |
| ------------- | ------------ | ---------------- |
| Union         | ✅           | –                |
| Concatenation | ✅           | –                |
| Kleene Star   | ✅           | –                |
| Intersection  | ❌           | –                |
| Complement    | ❌           | –                |

✅ That means CFLs are closed under “+”, “.”, and “\*”<br>
❌ Not closed under “∩” or “¬”.

---

## Quick Summary

| Concept             | Description                                    |
| ------------------- | ---------------------------------------------- |
| CFG                 | Grammar with one non-terminal on LHS           |
| Parse Tree          | Graphical derivation of string                 |
| Ambiguous Grammar   | More than one parse tree for same string       |
| CNF                 | A → BC or A → a                                |
| GNF                 | A → aα                                         |
| PDA                 | Finite Automaton + Stack                       |
| PDA ≡ CFG           | Recognize/generate same class of languages     |
| Pumping Lemma (CFL) | Prove a language is not context-free           |
| Closure             | Closed under ∪, ⋅, \*; not under ∩, complement |
