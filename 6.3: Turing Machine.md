### **_Section 6.3 — Turing Machine_**

---

### 1. Introduction

A **Turing Machine (TM)** is a **mathematical model of computation** proposed by _Alan Turing (1936)_.
It is the most powerful abstract model of computation and can simulate any algorithm or computer program.

**Think of it as an imaginary computer** simple but capable of performing anything that’s _computable_.

---

### 2. Structure of a Turing Machine

A Turing Machine consists of:

1. **Tape:** Infinite in both directions, divided into cells. Each cell stores one symbol.
2. **Tape Head:** Can **read**, **write**, and **move** one cell **left (L)** or **right (R)**.
3. **Finite Control (Brain):** Keeps track of the current state and determines what to do next.

---

### 3. Formal Definition

A Turing Machine is a **7-tuple**:

[
M = (Q, Σ, Γ, δ, q_0, q_{accept}, q_{reject})
]

| Symbol       | Meaning                                           |
| :----------- | :------------------------------------------------ |
| **Q**        | Finite set of states                              |
| **Σ**        | Input alphabet (symbols allowed in input)         |
| **Γ**        | Tape alphabet (includes Σ and the blank symbol ☐) |
| **δ**        | Transition function — decides next move           |
| **q₀**       | Start state                                       |
| **q_accept** | Accepting (final) state                           |
| **q_reject** | Rejecting (halting) state                         |

---

### 4. Transition Function (δ)

The transition function defines the machine’s behavior:

[
δ: Q × Γ → Q × Γ × {L, R}
]

That means:

- Based on **current state** and **current tape symbol**,
  TM will:

  - Move to a **new state**,
  - **Write** a symbol on the tape,
  - **Move** Left or Right.

---

### 5. Acceptance of a String

A string is **accepted** by a Turing Machine if:

- The machine **enters the accept state** after processing the entire string.
  Otherwise, if it halts in the **reject state**, the string is **not accepted**.

---

### 6. Turing Machine as a Language Recognizer

- A TM that accepts all strings belonging to a language **L** is called a **language recognizer**.
- Such languages are called **Turing-recognizable** or **recursively enumerable languages**.

---

### 7. Turing Machine as a Computing Function

TM can perform **computation** like addition, subtraction, string reversal, etc.
<br>It takes input → processes → halts with an **output** on the tape.

Hence, it acts as a **computing device**.

---

### 8. Turing Machine as an Enumerator

TM can also **enumerate (list)** all strings of a language.<br>
It prints strings of the language one by one on the tape.

---

### 9. Types of Turing Machines

| Type                           | Description                                                                                            |
| ------------------------------ | ------------------------------------------------------------------------------------------------------ |
| **Single Tape TM**             | Basic form with one tape and one head.                                                                 |
| **Multi-Tape TM**              | Has multiple tapes and heads — easier to design but equivalent in power to single-tape TM.             |
| **Multi-Track TM**             | A single tape divided into multiple tracks; each track stores different information.                   |
| **Non-Deterministic TM (NTM)** | Can take multiple transitions for the same input; if any path leads to acceptance, string is accepted. |
| **Universal TM (UTM)**         | A general-purpose TM that can simulate any other TM (like a modern computer).                          |

---

### 10. Church–Turing Thesis

**Statement:**

> Anything that can be computed by any mechanical procedure can also be computed by a Turing Machine.

This means Turing Machine defines the **limits of computation**.

---

### 11. Encoding of Turing Machine (Universal TM)

A **Universal Turing Machine (UTM)** can simulate any other TM when given the description (encoding) of that TM and its input.

Example:
If M is a Turing Machine and w is its input,
then U(M, w) simulates M on w.

Analogy:
Your **computer** is like a **Universal Turing Machine** which can run any program (encoded TM).

---

### 12. Computational Complexity

Turing Machines help define **time and space complexity**:

| Type                 | Description                                        |
| -------------------- | -------------------------------------------------- |
| **Time Complexity**  | Number of transitions (steps) made before halting. |
| **Space Complexity** | Number of tape cells used before halting.          |

---

### 13. Classes of Problems

| Class                    | Meaning                                                                                                  |
| ------------------------ | -------------------------------------------------------------------------------------------------------- |
| **P**                    | Problems solvable in _polynomial time_ (efficient).                                                      |
| **NP**                   | Problems verifiable in _polynomial time_.                                                                |
| **NP-Complete**          | Hardest problems in NP: if any NP-complete problem is solved in polynomial time, all NP problems can be. |
| **Undecidable Problems** | No TM can decide them (e.g., Halting Problem).                                                           |

---

### 14. Intractability

A problem is **intractable** if:

- It is **computable**, but
- Requires **unreasonable (huge)** time or space to solve.

Example:
Finding the best route visiting N cities (Traveling Salesman Problem) : exponential time.

---

### 15. Reducibility

A problem A is **reducible** to problem B** if**:

- A can be transformed into B using a computable function.

This helps in **classifying complexity**:

- If A reduces to B and B is decidable ⇒ A is also decidable.

## 10 Conceptual MCQs (with Answers)

1. **Turing Machine was proposed by:**<br>
   a) John von Neumann <br>b) Alan Turing <br>c) Charles Babbage <br>d) Alonzo Church

   → **b) Alan Turing**

2. **Which of the following is not a component of TM?**<br>
   a) Tape <br>b) Tape head <br>c) Stack <br>d) Finite control

   → **c) Stack**

3. **A Turing Machine can move:**<br>
   a) Only left <br>b) Only right <br>c) Both left and right <br>d) None

   → **c) Both left and right**

4. **TM is more powerful than PDA because it has:**<br>
   a) Multiple tapes <br>b) A tape of infinite length <br>c) Multiple heads <br>d) Multiple stacks

   → **b) A tape of infinite length**

5. **A Universal Turing Machine is used to:**<br>
   a) Recognize all languages <br>b) Simulate other TMs <br>c) Minimize states <br>d) Decide regular languages

   → **b) Simulate other TMs**

6. **The Church–Turing Thesis relates to:**<br>
   a) Power of Finite Automata<br> b) Limits of computation<br> c) Context-free grammar<br> d) Recursive functions only

   → **b) Limits of computation**

7. **Which of the following problems is undecidable?**<br>
   a) Palindrome checking<br> b) Halting problem<br> c) Addition of numbers<br> d) Multiplication of numbers

   → **b) Halting problem**

8. **A problem that can be computed but takes exponential time is:**<br>
   a) Decidable<br> b) Intractable<br> c) Undecidable<br> d) Tractable

   → **b) Intractable**

9. **Reducibility helps in:**<br>
   a) State minimization <br>b) Finding equivalent grammars <br>c) Classifying problem complexity <br>d) Determining PDA language

   → **c) Classifying problem complexity**

10. **Which of the following statements is TRUE?**<br>
    a) Multi-tape TM is more powerful than single-tape TM<br>
    b) PDA = TM<br>
    c) TM and Multi-tape TM are equivalent in power<br>
    d) FA = TM

    → **c) TM and Multi-tape TM are equivalent in power**
