### **_Section 6.4 Introduction of Computer Graphics_**

---

### 1. Overview of Computer Graphics

**Computer Graphics** is the field of study that deals with **generating, manipulating, and displaying visual content using computers.**

#### Applications:

- **Entertainment:** Animation, movies, games
- **Design:** CAD/CAM, architecture, industrial design
- **Education:** Visualization, simulations
- **Medicine:** Imaging, surgery simulations
- **Data Visualization:** Graphs, charts, dashboards

#### Two Main Types:

1. **Interactive Graphics:** User controls the image (e.g., CAD, games)
2. **Non-interactive Graphics:** Predefined output only (e.g., movie animation rendering)

---

### 2. Graphics Hardware

Graphics hardware includes **all physical components** used for input/output of graphics data.

---

#### **a. Display Technologies**

1. **Raster-Scan Display (Most common)**

   - Made of **pixels** arranged in rows and columns.
   - Each frame is **scanned line by line** from top to bottom.
   - Used in **monitors, TVs, smartphones**.
   - Example: CRT, LED, LCD displays.

   **Advantages:**

   - Supports full-color images.
   - Can display realistic graphics.

   **Disadvantages:**

   - Refresh rate needed to prevent flicker.

---

2. **Random-Scan (Vector Display)**

   - Draws **lines and curves directly** rather than scanning all pixels.
   - Used in **older oscilloscopes, early CAD systems**.

   **Advantage:** Very sharp line display.<br>
   **Disadvantage:** Not suitable for complex images (too slow).

---

#### **b. Architecture of Raster-Scan Displays**

Main components:

1. **Frame Buffer (Video Memory):**
   Stores pixel values for the screen. Each pixel = color/intensity.

2. **Display Controller:**
   Reads frame buffer data and sends it to the display.

3. **Digital-to-Analog Converter (DAC):**
   Converts pixel data (digital) to signals (analog) for display.

4. **Monitor (CRT/LCD):**
   Shows the image line by line.

**Frame Buffer Example:**

- If resolution = 1024 × 768 and color depth = 24 bits<br>
  → Memory = 1024 × 768 × 3 bytes ≈ 2.25 MB

---

#### **c. Display Processors (Graphics Controllers)**

- Specialized processors that handle rendering tasks.
- Reduces CPU load.
- Examples: **GPU (Graphics Processing Unit)**, **Display Adapter**, **Video Card**.
- Performs:

  - Coordinate transformations
  - Line/curve drawing
  - Clipping, shading, rasterization

---

#### **d. Output Devices**

| Device        | Function                                      |
| ------------- | --------------------------------------------- |
| **Monitor**   | Visual output of graphics                     |
| **Plotter**   | Produces large-scale, high-precision drawings |
| **Printer**   | Hard copy of graphics                         |
| **Projector** | Enlarged display on screen/wall               |

---

#### **e. Input Devices**

| Device               | Function                             |
| -------------------- | ------------------------------------ |
| **Keyboard**         | Text & command input                 |
| **Mouse**            | Positioning, selecting objects       |
| **Light Pen**        | Directly interact with screen pixels |
| **Joystick**         | Used in games, simulations           |
| **Digitizer/Tablet** | Drawing and design                   |
| **Scanner**          | Converts image to digital form       |
| **Touch Screen**     | Direct manipulation input            |

---

### 3. Graphics Software

**Graphics software** is used to design, edit, or render images and animations.

#### Categories:

1. **Application Software:**

   - AutoCAD, Blender, Photoshop, Maya, CorelDraw, Illustrator.

2. **Programming Libraries & APIs:**

   - **OpenGL**, **DirectX**, **Vulkan**, **WebGL**.

3. **Device Drivers:**

   - Interface between software and hardware (e.g., GPU driver).

---

### 4. Software Standards

Standardization ensures compatibility and portability.

| Standard                                                          | Description                                              |
| ----------------------------------------------------------------- | -------------------------------------------------------- |
| **OpenGL (Open Graphics Library)**                                | Platform-independent API for rendering 2D/3D graphics    |
| **DirectX (Microsoft)**                                           | API for Windows graphics, games, and multimedia          |
| **Vulkan**                                                        | Modern, low-overhead cross-platform graphics API         |
| **PHIGS (Programmer’s Hierarchical Interactive Graphics System)** | Early 3D graphics standard for professional applications |

---

### Summary

| Concept           | Key Points                       |
| ----------------- | -------------------------------- |
| Computer Graphics | Visualization using computers    |
| Raster Display    | Pixel-based, used in monitors    |
| Vector Display    | Line-based, used in older CAD    |
| Frame Buffer      | Stores pixel data                |
| GPU               | Handles rendering                |
| Input Devices     | Mouse, keyboard, light pen, etc. |
| Graphics APIs     | OpenGL, DirectX, Vulkan          |
| Output Devices    | Monitor, printer, plotter        |
