## 7.1 — Introduction to Data Structure, List, Linked Lists, and Trees

### 1. Data Types, Data Structures, and Abstract Data Types (ADT)

#### **Data Type**

- Defines **what kind of data** can be stored and **what operations** can be performed on it.
- **Examples:** `int`, `float`, `char`, `bool`

In simple words: _It tells the compiler how to interpret the data._

#### **Data Structure**

- A **way of organizing and storing data** efficiently in memory for fast access and modification.
- **Examples:** Array, Stack, Queue, Linked List, Tree, Graph, etc.

Think of it as _how data is arranged in memory._

#### **Abstract Data Type (ADT)**

- ADT = _what operations are performed_ (not _how_ they’re implemented).
- It defines **behavior**, not implementation.

**Example:**
A **Stack** ADT defines operations like:

- `push(x)` → insert
- `pop()` → remove
- `isEmpty()` → check empty

It doesn’t tell you whether stack is implemented using array or linked list that’s internal.

**Exam Tip:**

- _ADT = logical description_
- _Data Structure = physical implementation_

---

### 2. Time and Space Analysis of Algorithms

When we write algorithms, we analyze:

1. **Time Complexity:** How execution time increases with input size.
2. **Space Complexity:** How much memory is needed.

---

#### **Asymptotic Notations**

| Notation    | Meaning     | Description                |
| ----------- | ----------- | -------------------------- |
| **O(f(n))** | _Big O_     | Upper bound — worst case   |
| **Ω(f(n))** | _Big Omega_ | Lower bound — best case    |
| **Θ(f(n))** | _Big Theta_ | Tight bound — average case |

<br>
 Example:
For Linear Search (scanning array of `n` items):

- Best case: Ω(1)
- Worst case: O(n)
- Average case: Θ(n)

  **Exam Tip:**

- “At most” → Big O
- “At least” → Big Omega
- “Exactly or tightly bounded” → Big Theta

---

### 3. Linear Data Structures

Linear means data elements are **arranged sequentially**.

#### Types:

1. **Array**
2. **Stack**
3. **Queue**
4. **Linked List**

---

#### **Stack**

- **LIFO** (Last In First Out)
- Think of stack of plates: last plate added is the first one removed.

**Operations:**

- `push(x)` → insert element
- `pop()` → remove top element
- `peek()` → view top element
- `isEmpty()` → check empty

**Applications:**

- Expression evaluation
- Function calls (recursion)
- Undo/Redo in software

---

#### **Queue**

- **FIFO** (First In First Out)
- Think of people standing in a line.

**Operations:**

- `enqueue(x)` → insert at rear
- `dequeue()` → remove from front
- `isEmpty()` → check empty

**Types of Queue:**

1. **Simple Queue**
2. **Circular Queue**
3. **Priority Queue**
4. **Deque (Double Ended Queue)**

**Exam Tip:**

- Stack → LIFO
- Queue → FIFO

---

### 4. Stack Applications — Expression Conversion

#### **Infix → Postfix Conversion**

Example: `A + B * C`

- Infix = Operators between operands
- Postfix = Operators after operands → `A B C * +`

**Algorithm:**

1. Scan expression left to right
2. If operand → output
3. If operator → push to stack (based on precedence)
4. If `)` → pop till `(`
5. At end → pop all operators

**Precedence Order:**
`()` > `^` > `*` `/` > `+` `-`

---

#### **Postfix Evaluation**

Example: `6 2 3 + * 4 /`
Steps:

1. Read left to right
2. Push operands
3. When operator found → pop two operands, apply operation, push result

Result = 7.5

**Exam Tip:**

- Conversion uses **stack for operators**
- Evaluation uses **stack for operands**

---

### 5. Array Implementation of Lists

- A **list** is a collection of ordered elements.
- Implemented using **arrays** or **linked lists**.

Array-based list:

- Easy random access (O(1))
- Fixed size
- Insertion/deletion costly (O(n))

---

### 6. Static and Dynamic List Structures

| Type        | Memory Allocation              | Example     |
| ----------- | ------------------------------ | ----------- |
| **Static**  | Fixed size (compile time)      | Array       |
| **Dynamic** | Size can grow/shrink (runtime) | Linked List |

---

### 7. Linked List

#### **Definition:**

A linked list is a **collection of nodes** where each node contains:

1. **Data**
2. **Pointer** to the next node

---

#### **Types:**

| Type                     | Description                                |
| ------------------------ | ------------------------------------------ |
| **Singly Linked List**   | Each node points to next node only         |
| **Doubly Linked List**   | Each node points to next and previous node |
| **Circular Linked List** | Last node points back to first node        |

---

#### **Basic Operations:**

1. **Creation**
2. **Insertion** (at beginning, middle, end)
3. **Deletion** (from beginning, middle, end)
4. **Traversal**

**Exam Tips:**

- Head pointer → points to first node
- Last node → `NULL` (in non-circular)
- Doubly linked list allows **two-way traversal**
- Circular → **no NULL pointer**

---

### 8. Trees (Basics + Binary Trees)

#### **Definition:**

A **Tree** is a **non-linear hierarchical data structure** consisting of nodes connected by edges.

- **Root node:** Topmost node
- **Child/Parent:** Relation between connected nodes
- **Leaf node:** Node with no children

---

#### **Binary Tree:**

- Each node has **at most two children** : left and right.

**Common Operations:**

1. **Insertion**
2. **Deletion**
3. **Traversal**
4. **Search**

---

#### **Tree Traversals**

| Type           | Order               | Example (A is root) |
| -------------- | ------------------- | ------------------- |
| **Pre-order**  | Root → Left → Right | A B D E C           |
| **In-order**   | Left → Root → Right | D B E A C           |
| **Post-order** | Left → Right → Root | D E B C A           |

---

#### **Height, Level, Depth**

- **Height:** No. of edges on longest path from node to leaf
- **Depth:** No. of edges from root to that node
- **Level:** Depth + 1

---

#### **AVL Tree**

- **Self-balancing binary search tree**
- |Height(left) − Height(right)| ≤ 1 for every node
- Maintains balance using **rotations** (LL, RR, LR, RL)

  **Exam Tip:**

- AVL → “Adelson-Velsky and Landis”
- Keeps tree balanced for faster search (O(log n))

---

### **Quick Recap**

| Concept               | Keyword to Remember      |
| --------------------- | ------------------------ |
| ADT                   | Logical description only |
| Stack                 | LIFO                     |
| Queue                 | FIFO                     |
| Linked List           | Dynamic structure        |
| Doubly Linked List    | Two-way traversal        |
| Circular List         | No NULL                  |
| Infix → Postfix       | Uses Stack               |
| Binary Tree Traversal | Pre, In, Post            |
| AVL Tree              | Self-balancing BST       |
| Big O                 | Worst case upper bound   |

## MCQ Practice

**1. Which of the following defines an Abstract Data Type (ADT)?**<br>
A. Implementation details of data<br>
B. Logical behavior of data and operations<br>
C. Physical structure of data in memory<br>
D. The syntax of data declaration<br>

**Answer:** B<br>
ADT describes _what operations_ are performed, not _how_ they’re implemented.

---

**2. What is the time complexity of searching an element in a sorted array using Binary Search?**<br>
A. O(n)<br>
B. O(log n)<br>
C. O(n²)<br>
D. O(1)<br>

**Answer:** B<br>
Binary search halves the search space every time → log₂n steps.

---

**3. In a stack, the element deleted first is:**<br>
A. The one inserted first<br>
B. The one inserted last<br>
C. The smallest element<br>
D. The largest element<br>

**Answer:** B<br>
Stack = **LIFO** (Last In First Out).

---

**4. Which of the following data structures allows insertion and deletion only at one end?**<br>
A. Queue<br>
B. Stack<br>
C. Linked List<br>
D. Tree<br>

**Answer:** B<br>
Only Stack has both operations on the **same end (top)**.

---

**5. Which of the following statements about queues is true?**<br>
A. Insertion and deletion happen at the same end<br>
B. Insertion → rear, Deletion → front<br>
C. Both operations at front<br>
D. Both operations at rear<br>

**Answer:** B<br>
Queue = **FIFO**, insert at rear, remove from front.

---

**6. Which of the following is a dynamic data structure?**<br>
A. Array<br>
B. Static List<br>
C. Linked List<br>
D. Stack implemented by array<br>

**Answer:** C<br>
Linked list grows/shrinks at runtime (dynamic memory allocation).

---

**7. Which traversal of a binary tree prints nodes in sorted order (for BST)?**<br>
A. Preorder<br>
B. Postorder<br>
C. Inorder<br>
D. Level order<br>

**Answer:** C<br>
Inorder traversal of a BST always yields sorted data.

---

**8. Which of the following is NOT a type of linked list?**<br>
A. Circular linked list<br>
B. Doubly linked list<br>
C. Sequential linked list<br>
D. Singly linked list<br>

**Answer:** C<br>
“Sequential” refers to arrays, not linked lists.

---

**9. The height difference between left and right subtrees in an AVL tree can be:**<br>
A. At most 2<br>
B. At most 1<br>
C. At most n/2<br>
D. Exactly 0<br>

**Answer:** B<br>
AVL property: |height(left) − height(right)| ≤ 1

---

**10. What is the space complexity of an algorithm?**<br>
A. Maximum time it takes to run<br>
B. Total number of instructions executed<br>
C. Amount of memory required during execution<br>
D. Total input size<br>

**Answer:** C<br>
Space complexity = total memory (variables, data, recursion stack, etc.)

---

**Quick Recap**

- Stack → LIFO
- Queue → FIFO
- Linked List → Dynamic
- Inorder of BST → Sorted
- AVL Tree → Height diff ≤ 1
- Big O → Worst case
- Binary Search → O(log n)
