## 7.2 — Sorting, Searching, and Graphs

### 1. Types of Sorting

Sorting = arranging data in **ascending or descending** order.

#### **Based on where sorting occurs:**

| Type              | Description                                   | Example                      |
| ----------------- | --------------------------------------------- | ---------------------------- |
| **Internal Sort** | Entire data fits into main memory             | Bubble, Selection, Insertion |
| **External Sort** | Data too large → uses secondary memory (disk) | Merge Sort                   |

_Tip:_<br>
“Internal” = RAM sort; “External” = Disk sort.

---

### 2. Common Sorting Algorithms (and their complexity)

| Sorting            | Type                       | Best       | Avg        | Worst      | Stable? |
| ------------------ | -------------------------- | ---------- | ---------- | ---------- | ------- |
| **Bubble Sort**    | Exchange                   | O(n)       | O(n²)      | O(n²)      | Yes     |
| **Selection Sort** | Selection                  | O(n²)      | O(n²)      | O(n²)      | No      |
| **Insertion Sort** | Insertion                  | O(n)       | O(n²)      | O(n²)      | Yes     |
| **Merge Sort**     | Divide & Conquer           | O(n log n) | O(n log n) | O(n log n) | Yes     |
| **Quick Sort**     | Divide & Conquer           | O(n log n) | O(n log n) | O(n²)      | No      |
| **Heap Sort**      | Selection / Priority Queue | O(n log n) | O(n log n) | O(n log n) | No      |
| **Radix Sort**     | Non-comparison             | O(nk)      | O(nk)      | O(nk)      | Yes     |
| **Shell Sort**     | Generalized insertion      | O(n log n) | –          | O(n²)      | No      |

_Memory tricks:_

- **Stable sorts:** Bubble, Insertion, Merge, Radix
- **Fastest (average):** Quick Sort
- **Most predictable:** Merge Sort (always O(n log n))

---

### 3. Searching Techniques

| Method                         | Requirement        | Time Complexity | Notes            |
| ------------------------------ | ------------------ | --------------- | ---------------- |
| **Sequential (Linear) Search** | Unsorted data      | O(n)            | Simple, slow     |
| **Binary Search**              | Sorted data        | O(log n)        | Divide & Conquer |
| **Tree Search (BST)**          | Binary Search Tree | O(h)            | h = tree height  |

_Binary Search key idea:_<br>
Find mid → compare → half the range each time.

---

### 4. Hashing

Used for **fast data lookup** using a key.

#### **Concept:**

- **Hash function:** maps key → index in hash table<br>
  Example: `h(key) = key % table_size`

#### **Collision:**

Two keys map to same index.

#### **Collision Resolution Techniques:**

1. **Open Addressing**

   - _Linear Probing:_ next slot sequentially
   - _Quadratic Probing:_ jump by squares (1², 2², 3², …)
   - _Double Hashing:_ use a second hash function

2. **Chaining**

   - Each table slot stores a linked list of collided keys.

_Exam Tip:_

- Collision handling = **Chaining or Probing**
- Load factor α = n / table_size

---

### 5. Graph Basics

#### **Graph:**

Collection of **vertices (nodes)** and **edges (connections)**

| Type                         | Description                      |
| ---------------------------- | -------------------------------- |
| **Undirected Graph**         | Edges have no direction          |
| **Directed Graph (Digraph)** | Edges have direction             |
| **Weighted Graph**           | Edges have cost/weight           |
| **Connected Graph**          | Path exists between every vertex |

---

#### **Graph Representation:**

1. **Adjacency Matrix** → 2D array (space O(V²))
2. **Adjacency List** → list of neighbors (space O(V+E))

For sparse graphs → **Adjacency List** is efficient.

---

### 6. Graph Traversal

#### **Depth First Search (DFS)**

- Go as deep as possible before backtracking.
- Uses **stack (recursion)**.

#### **Breadth First Search (BFS)**

- Visit all neighbors first (level-wise).
- Uses **queue**.

_Exam Tip:_
DFS → Stack; BFS → Queue.

---

### 7. Transitive Closure (Warshall’s Algorithm)

Used to find if **path exists between any two vertices**.

- Based on adjacency matrix.
- If there is a path from i→k and k→j, then i→j is reachable.

---

### 8. Topological Sorting

Ordering of vertices in a **DAG (Directed Acyclic Graph)**
such that all directed edges u→v, u appears before v.

**Methods:**

- **DFS-based**
- **BFS (Kahn’s Algorithm)**

_Only for DAGs!_

---

### 9. Minimum Spanning Tree (MST)

Connects all vertices with **minimum total weight** and **no cycle**.

| Algorithm       | Approach                                      | Key Idea                                             |
| --------------- | --------------------------------------------- | ---------------------------------------------------- |
| **Prim’s**      | Greedy                                        | Grow tree by adding cheapest edge from existing tree |
| **Kruskal’s**   | Greedy                                        | Add smallest edge if no cycle formed                 |
| **Round-Robin** | Simple edge selection variant (rare in exams) |                                                      |

_MST = total cost minimum, no cycle._

---

### 10. Shortest Path Algorithms

| Algorithm          | Type          | Key Feature                                              |
| ------------------ | ------------- | -------------------------------------------------------- |
| **Dijkstra’s**     | Greedy        | Finds shortest path from one source (no negative weight) |
| **Bellman-Ford**   | Dynamic Prog. | Handles negative weights                                 |
| **Floyd-Warshall** | Dynamic Prog. | All-pairs shortest path                                  |

_Exam Tip:_<br>
Dijkstra → single-source<br>
Warshall → transitive closure<br>
Floyd-Warshall → all pairs shortest path

## **Important Takeaways**

- Stable sorts: Bubble, Insertion, Merge
- DFS → Stack; BFS → Queue
- Binary Search → Sorted data
- Dijkstra → Positive weights only
- MST → No cycles, minimal cost
