## 7.5 — Introduction to OS and Process Management

### 1. Operating System (OS) Basics

**Definition:**

- OS is a **system software** that manages hardware and software resources and provides services to users and applications.

**Functions / Services of OS:**

1. **Process Management** → create, schedule, terminate processes
2. **Memory Management** → allocate/deallocate memory
3. **File System Management** → files, directories
4. **Device Management** → I/O devices
5. **User Interface** → CLI or GUI
6. **Security & Protection** → access control

**OS Components:**

- Kernel, Shell, File System, Device Drivers

---

### 2. Types of OS

| Type                               | Description                           | Example                   |
| ---------------------------------- | ------------------------------------- | ------------------------- |
| **Batch OS**                       | Jobs collected & processed in batches | Early IBM OS              |
| **Time-Sharing / Multitasking OS** | Allows multiple users/processes       | Linux, Windows            |
| **Real-Time OS**                   | Immediate response needed             | Robotics, Medical devices |
| **Distributed OS**                 | Manages multiple computers as one     | Hadoop, Network OS        |

---

### 3. Processes and Threads

**Process:** A program in execution.

- Has **Process ID, state, program counter, stack, memory**.

**Process States:**

1. **New** → created
2. **Ready** → waiting for CPU
3. **Running** → executing
4. **Waiting/Blocked** → waiting for I/O
5. **Terminated** → finished

**Thread:** Lightweight process within a process.

- Shares memory with parent process, faster creation, better CPU utilization.

---

### 4. Process Scheduling

**CPU Scheduling:** Decide which process runs next.

**Types of Scheduling Algorithms:**

| Algorithm                                | Type                      | Key Idea                |
| ---------------------------------------- | ------------------------- | ----------------------- |
| **FCFS (First Come First Serve)**        | Non-preemptive            | Queue order             |
| **SJF (Shortest Job First)**             | Non-preemptive            | Shortest burst time     |
| **SRTF (Shortest Remaining Time First)** | Preemptive                | Shortest remaining time |
| **Round Robin**                          | Preemptive                | Time quantum            |
| **Priority Scheduling**                  | Preemptive/Non-preemptive | Priority-based          |

<br>_Tip:_

- FCFS → Fair but slow
- SJF/SRTF → Optimal average waiting time
- RR → Good for time-sharing

---

### 5. Principles of Concurrency

**Concurrency:** Multiple processes execute overlapping in time.

**Problems:**

- **Race Condition:** Outcome depends on timing of processes.
- **Critical Section Problem:** Code segment that accesses shared resources must be exclusive.

**Solution Tools:**

1. **Mutual Exclusion:** Only one process in critical section
2. **Semaphore:** Variable used for signaling

   - **Binary Semaphore / Mutex:** 0 or 1 → lock/unlock
   - **Counting Semaphore:** Integer counter

3. **Monitors:** High-level mechanism encapsulating variables + operations
4. **Message Passing:** Communication via send/receive

---

### 6. Classical Synchronization Problems

1. **Producer-Consumer Problem**

   - Use buffer, semaphores to avoid overfill/underflow.

2. **Readers-Writers Problem**

   - Manage concurrent read & exclusive write access.

3. **Dining Philosophers Problem**

   - Prevent deadlock when multiple processes compete for shared resources.
