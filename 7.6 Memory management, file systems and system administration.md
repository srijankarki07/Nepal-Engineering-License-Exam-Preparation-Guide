## 7.6 — Memory Management, File Systems, and System Administration

### 1. Memory Management Basics

**Memory Addressing:**

- Each byte of memory has a unique address.

**Memory Management Goals:**

1. Allocate memory efficiently to processes
2. Maximize CPU utilization
3. Avoid memory fragmentation

**Techniques:**

- **Swapping:** Move processes in/out of memory to disk to free space
- **Contiguous Allocation:** Process gets continuous memory block
- **Non-contiguous Allocation:** Paging, segmentation

---

### 2. Virtual Memory

- **Concept:** Process can use **more memory than physically available**
- OS maps **virtual addresses → physical addresses** using **page tables**

**Key Terms:**

- **Page:** Fixed-size block of virtual memory
- **Frame:** Fixed-size block of physical memory
- **Page Fault:** Required page not in memory → fetch from disk

---

### 3. Page Replacement Algorithms

Used when memory is full and new page needs to be loaded.

| Algorithm                     | Key Idea                                                |
| ----------------------------- | ------------------------------------------------------- |
| **FIFO (First In First Out)** | Replace the oldest page                                 |
| **LRU (Least Recently Used)** | Replace page unused for longest time                    |
| **Optimal**                   | Replace page that won’t be used for longest future time |
| **Clock / Second Chance**     | Circular queue with reference bit                       |

<br> _Tip:_

- LRU = Most commonly asked
- Optimal = Theoretical best

---

### 4. File System Concepts

- **File:** Collection of related data
- **Directory:** Organizes files
- **File Path:** Location of file in directory hierarchy

**File Allocation Methods:**

1. **Contiguous Allocation:** Blocks stored sequentially → fast access
2. **Linked Allocation:** Each block points to next → flexible size
3. **Indexed Allocation:** Index block holds addresses of file blocks → random access

**Fragmentation:**

- **External:** Free space exists but not contiguous
- **Internal:** Allocated block partially used

---

### 5. File System Implementation

- Mapping file blocks to disk
- Maintaining free space tables / bitmaps
- Caching and buffering for performance

---

### 6. System Administration Tasks

1. **User Account Management:** Create, delete, modify users
2. **Start / Shutdown Procedures:** Boot sequence, graceful shutdown
3. **Resource Monitoring:** CPU, memory, disk usage
4. **Backup & Restore**

<br> _Tip:_

- MCQs often ask: “Which task is admin responsibility?” → User accounts, backups, startup/shutdown

---

### Quick Summary Table

| Concept          | Key Idea                                |
| ---------------- | --------------------------------------- |
| Virtual Memory   | Logical > Physical memory, uses paging  |
| Page Replacement | FIFO, LRU, Optimal                      |
| File Allocation  | Contiguous, Linked, Indexed             |
| Fragmentation    | Internal / External                     |
| System Admin     | User accounts, startup/shutdown, backup |

## MCQs

**1. Virtual memory allows:**<br>
A. Using more memory than physically available<br>
B. Less memory than available<br>
C. Direct disk access only<br>
D. Only single process execution

**Answer:** A

---

**2. Page replacement algorithm using oldest page:**<br>
A. LRU<br>
B. FIFO<br>
C. Optimal<br>
D. Clock

**Answer:** B

---

**3. Page fault occurs when:**<br>
A. Page is in memory<br>
B. Page is not in memory<br>
C. CPU is idle<br>
D. Process terminates

**Answer:** B

---

**4. File blocks stored sequentially refers to:**<br>
A. Contiguous allocation<br>
B. Linked allocation<br>
C. Indexed allocation<br>
D. Virtual allocation

**Answer:** A

---

**5. Indexed allocation uses:**<br>
A. Single continuous block<br>
B. Linked list of blocks<br>
C. Index block pointing to data blocks<br>
D. Heap memory

**Answer:** C

---

**6. External fragmentation occurs when:**<br>
A. Allocated memory is partially used<br>
B. Free space exists but not contiguous<br>
C. Disk full<br>
D. Page table overflow

**Answer:** B

---

**7. Which of the following is NOT a system administration task?**<br>
A. User account management<br>
B. CPU scheduling<br>
C. Startup/shutdown procedures<br>
D. Backup and restore

**Answer:** B

---

**8. Swapping in memory management:**<br>
A. Moves pages within memory<br>
B. Moves processes between memory and disk<br>
C. Deletes processes permanently<br>
D. Allocates contiguous memory

**Answer:** B

---

**9. LRU page replacement chooses:**<br>
A. Oldest page<br>
B. Most recently used page<br>
C. Least recently used page<br>
D. Random page

**Answer:** C

---

**10. Which file allocation supports random access efficiently?**<br>
A. Contiguous<br>
B. Linked<br>
C. Indexed<br>
D. Sequential

**Answer:** C
