## 9.1 Introduction to AI and Intelligent Agents

### Concept of Artificial Intelligence (AI)

- **Definition:**
  Artificial Intelligence is the **science of making machines (especially computers) think and act like humans**. <br>
  It enables computers to **learn, reason, plan, perceive, and understand language**.

- **Simplified idea:**
  AI = Machine + Intelligence (ability to make decisions, solve problems, or adapt)

---

### AI Perspectives

There are **two main dimensions** (based on thinking and acting):

| Perspective             | Example                 | Meaning                                             |
| ----------------------- | ----------------------- | --------------------------------------------------- |
| **Thinking Humanly**    | Cognitive modeling      | Make computers think like humans do.                |
| **Acting Humanly**      | Turing Test approach    | Make computers behave like humans.                  |
| **Thinking Rationally** | Laws of thought         | Use logical reasoning to reach correct conclusions. |
| **Acting Rationally**   | Rational agent approach | Take actions that maximize goal achievement.        |

Most modern AI systems are based on the **“Acting Rationally”** perspective (intelligent agents).

---

### History of AI (Quick Timeline)

| Year              | Milestone                                                             |
| ----------------- | --------------------------------------------------------------------- |
| **1943**          | McCulloch & Pitts – first mathematical model of a neuron.             |
| **1950**          | Alan Turing – _Turing Test_ proposed.                                 |
| **1956**          | John McCarthy coined the term “Artificial Intelligence”.              |
| **1960s–70s**     | Symbolic AI, early expert systems.                                    |
| **1980s**         | Machine learning and neural networks revival.                         |
| **1990s–2000s**   | Data mining, computer vision, NLP progress.                           |
| **2010s–present** | Deep Learning, reinforcement learning, generative AI (ChatGPT, etc.). |

### Applications of AI

- **Expert Systems:** Decision-making in medicine, finance, etc.
- **NLP:** Chatbots, translators.
- **Robotics:** Self-driving cars, drones.
- **Computer Vision:** Face/object recognition.
- **Gaming:** Chess, Go.
- **Recommendation Systems:** Netflix, YouTube.
- **Speech Recognition:** Siri, Alexa.

### Foundations of AI

AI combines knowledge from:

- **Mathematics:** logic, probability, statistics
- **Psychology:** learning and cognition
- **Computer Science:** algorithms, programming
- **Neuroscience:** neural networks
- **Linguistics:** natural language understanding
- **Philosophy:** reasoning, consciousness

---

### Introduction to Agents

An **agent** is **anything that perceives its environment through sensors and acts upon it through actuators**.

Example:

- A **robot vacuum** has sensors (detect dirt, walls) and actuators (move, rotate brush).
- A **chess program** senses board position (input) and moves a piece (output).

---

### Structure of an Intelligent Agent

**Agent = Architecture + Program**

- **Architecture:** physical platform (robot, computer)
- **Program:** the logic controlling agent behavior

---

### Properties of Intelligent Agents

1. **Autonomy** – Operates without human control
2. **Reactivity** – Responds to environment changes
3. **Pro-activeness** – Goal-directed behavior
4. **Social ability** – Interacts with other agents/humans

---

### PEAS Description (Performance measure, Environment, Actuators, Sensors)

Used to **define an agent task environment**.

Example:

| Agent                | P                       | E              | A               | S              |
| -------------------- | ----------------------- | -------------- | --------------- | -------------- |
| **Self-driving car** | Safety, time, comfort   | Roads, traffic | Wheels, brakes  | Cameras, radar |
| **Vacuum cleaner**   | Cleanliness, energy use | Rooms, dirt    | Motors, suction | Dirt sensor    |

---

### Types of Agents

| Type                         | Description                                                     | Example                                        |
| ---------------------------- | --------------------------------------------------------------- | ---------------------------------------------- |
| **Simple Reflex Agent**      | Acts on current percept only; uses condition-action rules.      | Thermostat, light sensor.                      |
| **Model-Based Reflex Agent** | Keeps track of world’s state; uses internal model.              | Robot that avoids obstacles.                   |
| **Goal-Based Agent**         | Uses goals to decide actions.                                   | GPS navigation system.                         |
| **Utility-Based Agent**      | Chooses actions that maximize happiness/satisfaction (utility). | AI assistant optimizing battery + performance. |

---

### Environment Types

| Environment Type         | Meaning                             | Example           |
| ------------------------ | ----------------------------------- | ----------------- |
| **Deterministic**        | Next state is predictable.          | Chess.            |
| **Stochastic**           | Involves randomness.                | Poker.            |
| **Static**               | Does not change while agent thinks. | Crossword puzzle. |
| **Dynamic**              | Changes over time.                  | Driving.          |
| **Fully Observable**     | Agent can see entire state.         | Tic-tac-toe.      |
| **Partially Observable** | Agent sees only part.               | Poker.            |
| **Single Agent**         | Only one agent acts.                | Crossword solver. |
| **Multi-Agent**          | Multiple agents interact.           | Soccer game.      |

---

### Summary

1. AI that mimics human thinking → **Thinking Humanly**
2. AI coined by → **John McCarthy (1956)**
3. Agent = **Sensors + Actuators + Program + Architecture**
4. PEAS stands for → **Performance, Environment, Actuators, Sensors**
5. Reflex agent doesn’t have → **Memory or model**
6. Example of deterministic environment → **Chess**
7. Example of partially observable → **Poker**

### MCQs

**1.** Who coined the term “Artificial Intelligence”?<br>
A) Alan Turing<br>
B) John McCarthy<br>
C) Marvin Minsky<br>
D) Herbert Simon

**Answer:** B) John McCarthy

**2.** Which perspective of AI focuses on making machines act to achieve goals rationally?<br>
A) Thinking Humanly<br>
B) Acting Humanly<br>
C) Thinking Rationally<br>
D) Acting Rationally

**Answer:** D) Acting Rationally

**3.** What does PEAS stand for in defining an agent?<br>
A) Performance, Environment, Actions, Sensors<br>
B) Performance, Environment, Actuators, Sensors<br>
C) Problem, Environment, Actuators, Sensors<br>
D) Performance, Event, Actuators, Simulation

**Answer:** B) Performance, Environment, Actuators, Sensors

**4.** Which agent acts only based on the current percept?<br>
A) Model-Based Agent<br>
B) Goal-Based Agent<br>
C) Utility-Based Agent<br>
D) Simple Reflex Agent

**Answer:** D) Simple Reflex Agent

**5.** A self-driving car optimizing safety and comfort is an example of:<br>
A) Reflex Agent<br>
B) Utility-Based Agent<br>
C) Goal-Based Agent<br>
D) Model-Based Agent

**Answer:** B) Utility-Based Agent

**6.** Which environment is **deterministic**?<br>
A) Chess<br>
B) Poker<br>
C) Self-driving in traffic<br>
D) Stock Market

**Answer:** A) Chess

**7.** An environment that changes while the agent thinks is called:<br>
A) Static<br>
B) Dynamic<br>
C) Fully Observable<br>
D) Stochastic

**Answer:** B) Dynamic

**8.** Which property allows an agent to act independently without human intervention?<br>
A) Reactivity<br>
B) Autonomy<br>
C) Social ability<br>
D) Pro-activeness

**Answer:** B) Autonomy

**9.** What is an **internal model** of the world maintained by an agent called?<br>
A) Reflex system<br>
B) Model-based memory<br>
C) Goal set<br>
D) PEAS framework

**Answer:** B) Model-based memory

**10.** Partially observable environments:<br>
A) Provide complete information to the agent<br>
B) Are deterministic<br>
C) Provide incomplete information to the agent<br>
D) Are static

**Answer:** C) Provide incomplete information to the agent
