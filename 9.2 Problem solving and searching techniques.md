## 9.2 Problem Solving and Searching Techniques

### 1. Definition of a Problem

- **Problem:** A situation where an agent must move from an **initial state** to a **goal state** by taking a sequence of actions.
- **Problem Solving in AI:** Finding a sequence of actions that leads from the initial state to the goal state.

**Key points:**

- Initial State → Actions → Resulting State → Goal State
- Example: Solving a maze, playing chess, solving 8-puzzle.

---

### 2. Problem as a State Space Search

- **State Space:** The set of all possible configurations (states) of a problem.
- **Search:** Exploring the state space to find a solution.
- **State Space Representation:** Can be visualized as a **tree or graph**.

**Example:**
8-puzzle has 9! (362,880) possible states → search tree shows moves from initial to goal.

---

### 3. Problem Formulation

To solve a problem, define:

1. **Initial state** – where we start
2. **Actions** – possible moves at each state
3. **Transition model** – what result each action produces
4. **Goal test** – checks if current state is goal
5. **Path cost** – numerical cost of a path (optional for cost-based search)

---

### 4. Well-Defined Problems

- A problem is **well-defined** if it has:

  - Clearly defined **initial state**
  - **Goal state**
  - **Operators** to go from one state to another
  - **Path cost** (optional)

**Example:** 8-puzzle, Tic-Tac-Toe

---

### 5. Constraint Satisfaction Problem (CSP)

- **CSP:** Problem where states must satisfy constraints.
- **Components:** Variables, domains, constraints.
- **Example:** Sudoku, Map coloring, N-Queens problem

---

### 6. Uninformed (Blind) Search Techniques

- **Uninformed Search:** No knowledge about goal location; explores blindly.

| Search Type                          | How it Works                                          | Notes                                                          |
| ------------------------------------ | ----------------------------------------------------- | -------------------------------------------------------------- |
| **Breadth-First Search (BFS)**       | Explores all nodes at current depth before next depth | Guarantees shortest path, high memory usage                    |
| **Depth-First Search (DFS)**         | Explores deepest nodes first                          | Low memory, may not find shortest path, can get stuck in loops |
| **Depth-Limited Search (DLS)**       | DFS with max depth limit                              | Avoids infinite loops                                          |
| **Iterative Deepening Search (IDS)** | Repeated DLS with increasing depth                    | Combines BFS completeness + DFS memory efficiency              |
| **Bidirectional Search**             | Search from both initial and goal states              | Reduces search time, needs invertible goal                     |

---

### 7. Informed (Heuristic) Search Techniques

- Uses **heuristic function (h(n))** → estimate cost from current node to goal.

| Search Type                  | Key Idea                                               | Notes                                    |
| ---------------------------- | ------------------------------------------------------ | ---------------------------------------- |
| **Greedy Best-First Search** | Chooses node closest to goal (min h(n))                | Fast, not always optimal                 |
| **A\***                      | Uses f(n) = g(n) + h(n) (g = path cost, h = heuristic) | Finds optimal path if h(n) is admissible |
| **Hill Climbing**            | Always move to neighbor with better value              | Can get stuck in local maxima            |
| **Simulated Annealing**      | Occasionally allows worse moves to escape local maxima | Inspired by metal annealing              |

---

### 8. Game Playing and Adversarial Search

- **Game:** Multi-agent environment with opponents (adversaries).
- **Goal:** Choose moves to **maximize win chance**.

**Techniques:**

1. **Minimax Search:**

   - Assumes opponent plays optimally.
   - Maximizing agent chooses move with **max value**; opponent chooses **min value**.

2. **Alpha-Beta Pruning:**

   - Optimization to **skip branches** in Minimax that cannot affect final decision.
   - Reduces computation significantly.

---

### Summary

1. **State Space:** Set of all possible problem configurations
2. **CSP:** Solve using variables, domains, constraints
3. **BFS vs DFS:** BFS guarantees shortest path, DFS may not
4. **Heuristic Search:** Uses h(n) to guide search
5. **A\*** → f(n) = g(n) + h(n)
6. **Hill Climbing vs Simulated Annealing:** Hill climbing may get stuck in local maxima; SA avoids it
7. **Minimax:** Maximize own score, minimize opponent’s
8. **Alpha-Beta Pruning:** Cuts unnecessary branches in Minimax

---

### MCQs

**1.** What is the first step in problem-solving for AI?<br>
A) Define goal state<br>
B) Formulate problem<br>
C) Choose an algorithm<br>
D) Execute actions

**Answer:** B) Formulate problem

**2.** In a **well-defined problem**, which of the following is NOT required?<br>
A) Initial state<br>
B) Goal state<br>
C) Operators<br>
D) Programming language

**Answer:** D) Programming language

**3.** A problem where states must satisfy constraints is called:<br>
A) Uninformed Search Problem<br>
B) Constraint Satisfaction Problem<br>
C) Heuristic Problem<br>
D) Game Problem

**Answer:** B) Constraint Satisfaction Problem

**4.** Which search strategy explores all nodes at a given depth before going deeper?<br>
A) DFS<br>
B) BFS<br>
C) Hill Climbing<br>
D) A\*

**Answer:** B) BFS

**5.** Which search strategy combines path cost and heuristic estimate?<br>
A) Greedy Best-First Search<br>
B) A\* Search<br>
C) Iterative Deepening Search<br>
D) Depth-Limited Search

**Answer:** B) A\* Search

**6.** Hill Climbing search may fail due to:<br>
A) Infinite branching<br>
B) Local maxima<br>
C) Path cost<br>
D) Goal test

**Answer:** B) Local maxima

**7.** Simulated Annealing differs from Hill Climbing because it:<br>
A) Never evaluates neighbors<br>
B) May accept worse moves to escape local maxima<br>
C) Only searches breadth-first<br>
D) Guarantees optimal solution

**Answer:** B) May accept worse moves to escape local maxima

**8.** Minimax algorithm is used in:<br>
A) Single-agent search<br>
B) Multi-agent game playing<br>
C) Heuristic search<br>
D) Constraint satisfaction problems

**Answer:** B) Multi-agent game playing

**9.** Alpha-Beta Pruning is used to:<br>
A) Increase the depth of DFS<br>
B) Cut unnecessary branches in Minimax<br>
C) Solve constraint satisfaction problems<br>
D) Generate heuristics

**Answer:** B) Cut unnecessary branches in Minimax

**10.** Bidirectional Search works by:<br>
A) Searching forwards only<br>
B) Searching from initial and goal simultaneously<br>
C) Using heuristics to guide search<br>
D) Randomly exploring nodes

**Answer:** B) Searching from initial and goal simultaneously
