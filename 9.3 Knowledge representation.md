## 9.3 Knowledge Representation

### 1. What is Knowledge Representation?

- **Definition:** A way to **store and organize information** in AI so that a machine can **reason, make decisions, and solve problems**.
- **Goal:** Represent knowledge in a form that computers can **use efficiently for inference**.

**Key idea:** Knowledge Representation = **Knowledge + Reasoning**

---

### 2. Approaches to Knowledge Representation

1. **Logical Representation:** Uses formal logic to represent facts and rules.

   - Example: “All humans are mortal; Socrates is human; therefore, Socrates is mortal.”

2. **Semantic Networks:** Graphs showing relationships between concepts (nodes = concepts, edges = relationships).
3. **Frames:** Structured representation for objects with **slots and values**.

   - Example: Frame for “Car”: Slots = Color, EngineType, Fuel

4. **Rules / Production Systems:** IF–THEN rules to represent knowledge.

   - Example: IF temperature > 100 → THEN alarm ON

---

### 3. Issues in Knowledge Representation

- **Incomplete knowledge** → Some info may be missing
- **Ambiguity** → Same fact may have multiple meanings
- **Uncertainty** → Not all knowledge is 100% certain
- **Inconsistency** → Conflicting facts
- **Efficiency** → Must allow fast reasoning

---

### 4. Semantic Nets

- **Graphical representation** of concepts and their relationships.
- Nodes = concepts, Links = relationships.
- Example: “Dog → is-a → Animal”
- **MCQ tip:** Often asked: Difference between Semantic Net and Frame.

---

### 5. Frames

- **Frames = Object + Attributes (slots)**
- Each slot may have **default values** or **procedures**.
- Example:

  ```
  Frame: Car
  Slots: Color = Red, Engine = Diesel, Doors = 4
  ```

- Frames are like **structured objects in programming**.

---

### 6. Propositional Logic (PL)

- **Represents facts** using symbols (propositions) that are **true/false**.
- **Syntax:** Symbols + logical connectives (AND ∧, OR ∨, NOT ¬, IMPLIES →)
- **Semantics:** Meaning of propositions in terms of truth
- **Tautology:** Always true
- **Validity:** Logically correct
- **Well-Formed Formula (WFF):** Correct syntax

**Example:**

- “If it rains → ground is wet” → Rain = P, Wet = Q → P → Q

- **Inference:** Deduce new facts from existing ones

  - Using **Resolution method**

---

### 7. Predicate Logic (First-Order Logic, FOPL)

- Extends propositional logic **with objects, predicates, and quantifiers**.
- **Syntax:** Predicates, Constants, Variables
- **Quantifiers:**

  - ∀x = For all x (Universal)
  - ∃x = There exists x (Existential)

- **Rules of inference:** Modus Ponens, Generalization, etc.
- **Unification:** Matching expressions to apply rules
- **Resolution refutation system:** Prove statements by contradiction

**Example:**

- “All humans are mortal” → ∀x (Human(x) → Mortal(x))

---

### 8. Bayesian Reasoning

- **Bayes’ Rule:** Computes probability of an event given prior knowledge.
- Formula:

  ![alt text](./assets/bayesian.png)

- **Bayesian Networks:** Graphical model representing **probabilistic dependencies** between variables.
- **Applications:** Medical diagnosis, spam filtering

---

### Summary

1. **KR = Knowledge + Reasoning**
2. **Semantic Net** = Graph (nodes + edges)
3. **Frames** = Objects + Attributes + Values
4. **Propositional Logic** = True/False facts, WFF, connectives
5. **Predicate Logic** = Objects + Predicates + Quantifiers
6. **Bayes Rule** → P(A|B) = P(B|A)P(A)/P(B)
7. **Bayesian Network** = Probabilistic graphical model

### MCQs

**1.** Which of the following represents knowledge using nodes and links?<br>
A) Frame<br>
B) Semantic Network<br>
C) Predicate Logic<br>
D) Rule-Based System

**Answer:** B) Semantic Network

---

**2.** A frame is primarily used to represent:<br>
A) Relationships between concepts<br>
B) Objects with attributes and values<br>
C) Probabilities of events<br>
D) Logical inference rules

**Answer:** B) Objects with attributes and values

---

**3.** In propositional logic, which of the following is a logical connective?<br>
A) ∀ (for all)<br>
B) → (implies)<br>
C) Predicate<br>
D) Slot

**Answer:** B) → (implies)

---

**4.** A statement that is true in all situations is called:<br>
A) Contradiction<br>
B) Tautology<br>
C) Well-formed formula<br>
D) Predicate

**Answer:** B) Tautology

---

**5.** First-Order Predicate Logic extends propositional logic by adding:<br>
A) Nodes and links<br>
B) Objects, predicates, and quantifiers<br>
C) IF–THEN rules<br>
D) Heuristic evaluation

**Answer:** B) Objects, predicates, and quantifiers

---

**6.** In FOPL, ∀x (Human(x) → Mortal(x)) means:<br>
A) Some humans are mortal<br>
B) All humans are mortal<br>
C) No humans are mortal<br>
D) Mortal is a human

**Answer:** B) All humans are mortal

---

**7.** Which method is used to deduce new facts in propositional logic?<br>
A) Bayes’ Rule<br>
B) Resolution<br>
C) Hill Climbing<br>
D) Minimax

**Answer:** B) Resolution

---

**8.** Bayes’ Rule calculates:<br>
A) Logical truth of a statement<br>
B) Probability of an event given prior knowledge<br>
C) Optimal path in search<br>
D) Relationship between nodes in a semantic net

**Answer:** B) Probability of an event given prior knowledge

---

**9.** Bayesian Networks are primarily used for:<br>
A) Deterministic reasoning<br>
B) Probabilistic reasoning<br>
C) Reflex agents<br>
D) Game-playing AI

**Answer:** B) Probabilistic reasoning

---

**10.** Which of the following is an example of knowledge representation issue?<br>
A) Incomplete knowledge<br>
B) BFS vs DFS<br>
C) Hill Climbing<br>
D) Alpha-Beta pruning

**Answer:** A) Incomplete knowledge
