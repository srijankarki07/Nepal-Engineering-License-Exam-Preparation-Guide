## 9.4 Expert Systems and Natural Language Processing

### 1. Expert Systems (ES)

- **Definition:** Computer programs that **mimic human experts** to solve specific problems.
- **Key Idea:** Uses **knowledge + reasoning** to make decisions.

**Applications:**

- Medical diagnosis (MYCIN), Engineering, Financial decision-making.

---

### 2. Architecture of an Expert System

Components:

| Component                        | Function                                                  |
| -------------------------------- | --------------------------------------------------------- |
| **Knowledge Base**               | Stores facts and rules (declarative knowledge)            |
| **Inference Engine**             | Applies reasoning to the knowledge base to solve problems |
| **User Interface**               | Allows user interaction                                   |
| **Explanation System**           | Explains reasoning to user                                |
| **Knowledge Acquisition Module** | Helps gather knowledge from experts                       |

---

### 3. Knowledge Types

1. **Declarative Knowledge:** Facts (“Paris is the capital of France”)
2. **Procedural Knowledge:** How-to rules (“If fever > 101 → give paracetamol”)

---

### 4. Development of Expert Systems

**Steps:**

1. Identify problem domain
2. Gather knowledge from experts
3. Represent knowledge in rules/frames
4. Implement inference engine
5. Test and validate

---

### 5. Natural Language Processing (NLP)

- **Definition:** Enables machines to **understand, interpret, and generate human language**.
- **Two main tasks:**

  1. **Natural Language Understanding (NLU):** Understand input text/speech
  2. **Natural Language Generation (NLG):** Produce human-like language

**Applications:**

- Chatbots, Translation, Voice assistants, Text summarization

---

### 6. Steps in NLP

1. **Tokenization:** Break text into words/sentences
2. **Morphological Analysis:** Analyze word structure
3. **Syntactic Analysis (Parsing):** Check grammar
4. **Semantic Analysis:** Understand meaning
5. **Pragmatic Analysis:** Understand context
6. **Discourse Analysis:** Understand sentences in relation to each other
7. **Text Generation:** Create meaningful output

---

### 7. NLP Challenges

- Ambiguity in words/sentences
- Sarcasm, idioms, context understanding
- Multiple languages and grammar rules
- Handling incomplete or unstructured text

---

### 8. Machine Vision Concepts

- **Definition:** Enables machines to **see and interpret images/videos**.
- **Stages:**

  1. Image acquisition
  2. Preprocessing
  3. Feature extraction
  4. Recognition/interpretation

---

### 9. Robotics

- Robots = Agents that **sense environment + act physically**
- Applications: Industrial robots, Drones, Autonomous vehicles

---

### Summary

1. **Expert System** = Mimics human experts
2. **Knowledge Base** = Stores facts/rules
3. **Inference Engine** = Applies reasoning
4. **Declarative vs Procedural knowledge**
5. **NLU vs NLG** in NLP
6. **Tokenization → Parsing → Semantic analysis → Output**
7. **Machine Vision** = Seeing + interpreting
8. **Robotics** = Physical action + sensing

---
