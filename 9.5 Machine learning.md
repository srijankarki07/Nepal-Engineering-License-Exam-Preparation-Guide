## 9.5 Machine Learning

### 1. Introduction to Machine Learning

- **Definition:** Machine Learning is a branch of AI where machines **learn patterns from data** and **improve performance without explicit programming**.
- **Goal:** Make predictions, classify data, or optimize actions automatically.

**Key Idea:** Data → Learning Algorithm → Model → Prediction/Decision

---

### 2. Concepts of Learning

- **Learning** = Improving performance P on task T with experience E

  - Example: Chess-playing program improves by playing games

- **Types of ML based on feedback:**

---

### 3. Types of Machine Learning

| Type                       | Key Idea                                      | Example                           |
| -------------------------- | --------------------------------------------- | --------------------------------- |
| **Supervised Learning**    | Learn from **labeled data** (input → output)  | Email spam detection              |
| **Unsupervised Learning**  | Learn **patterns in unlabeled data**          | Customer segmentation, clustering |
| **Reinforcement Learning** | Learn by **trial and error**, maximize reward | Self-driving car, game AI         |

---

### 4. Inductive Learning

- Learns **general rules from examples**.
- **Decision Tree**: Popular inductive learning method

  - Splits data based on attribute values to classify examples
  - Example: If Weather=Sunny & Humidity=High → Play=No

---

### 5. Statistical-based Learning

- **Naive Bayes Model:** Probabilistic classifier based on **Bayes’ theorem**.
- Assumes features are **independent**.
- Example: Spam detection using word probabilities

---

### 6. Fuzzy Learning

- Handles **uncertain, imprecise, or vague data**.
- **Fuzzy Inference System (FIS):** Maps inputs to outputs using fuzzy rules.
- **Inference Methods:**

  - Mamdani method
  - Sugeno method

**Example:** Temperature = “High” → Fan speed = “Medium”

---

### 7. Genetic Algorithm (GA)

- **Inspired by natural selection** to solve optimization problems.
- **Components:**

  1. **Encoding:** Represent solution as chromosomes
  2. **Selection:** Choose best solutions for reproduction
  3. **Crossover (Recombination):** Exchange parts of solutions
  4. **Mutation:** Randomly alter parts to maintain diversity
  5. **Fitness Function:** Evaluate how good each solution is
  6. **Parameters:** Population size, mutation rate, crossover rate

**Example:** Optimizing route for delivery trucks

---

### Summary

1. **ML = Learning from data to improve performance**
2. **Supervised:** Labeled data → Output known
3. **Unsupervised:** No labels, find patterns
4. **Reinforcement:** Trial and error, maximize reward
5. **Decision Tree:** Inductive learning, splits data based on attributes
6. **Naive Bayes:** Statistical learning, features independent
7. **Fuzzy Learning:** Handles vague/imprecise data
8. **Genetic Algorithm:** Optimization inspired by evolution

## MCQs

**1.** Machine Learning primarily focuses on:<br>
A) Explicit programming<br>
B) Learning patterns from data<br>
C) Random actions<br>
D) Hard-coded rules

**Answer:** B) Learning patterns from data

---

**2.** Supervised learning uses:<br>
A) Labeled data<br>
B) Unlabeled data<br>
C) Trial and error<br>

**Answer:** A) Labeled data

---

**Answer:** B) Unsupervised
